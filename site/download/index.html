如何核对下载文件

  1. 从本页下载对应版本的安装包和 SHA256SUMS。
  2. 在终端或 PowerShell 中按系统说明计算 SHA-256。
  3. 将计算值与同一 GitHub Release 的校验文件逐字比对；不一致时不要安装。
