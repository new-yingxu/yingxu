功能

先把地基做对：复制不丢、校验不假、删除可撤。

影序不是又一个修图软件。它处理的是「这批素材到底安不安全」这件事——所以每一步都留下可复查的证据。

1 · 备份

选择来源目录与 1–8 个本地目的地，先生成计划再执行。计划里能看到文件数、总字节、目标可用空间，确认后才真正落盘。

  • 同一目标已存在相同文件则跳过，不覆盖、不改名
  • 任务可暂停、可取消、可恢复；失败项单独重试
  • 来源目录只读：不移动、不删除、不改时间戳

2 · 校验

每个副本都计算 SHA-256 并与来源比对。校验结果写进副本清单，之后任何时候都能「复查」。

  • 复制写盘后再读回复算，避免缓存骗过校验
  • 复查会重新读取磁盘，报告损坏或丢失的条目
  • 校验失败的文件不会标记为已备份

3 · 整理

按 EXIF 拍摄时间、机型、事件与自定义规则命名，支持预设预览与批量执行。

  • RAW 走内嵌 JPEG 预览，比全解码快一个数量级
  • 视频读 MP4/MOV 容器元数据：时长、分辨率、帧率、编码、码率、创建时间
  • 质量信号（高光、暗部、清晰度）只输出「待复核」，不自动删片

4 · Agent

用自然语言描述意图，由助理转成计划、解释失败原因、汇总报告。

  • 危险动作（删除、覆盖、转移）必须二次确认
  • 默认本地规则优先，可接入你自己的模型服务
  • 不上传原片，只上传你确认要同步的任务元数据

格式支持

类型支持程度说明
JPEG / PNG / TIFF / WebP / BMP完整解码、EXIF、缩略图、质量信号
RAW（CR2/CR3/NEF/ARW/RAF/DNG/ORF/RW2/PEF 等）预览级提内嵌 JPEG 预览 + 拍摄字段；不做高质量显影；BigTIFF 与部分新机型可能无预览
MP4 / MOV完整容器元数据；抽帧需系统存在 ffmpeg，否则只出元数据
其他视频容器（MKV/AVI/MTS…）未支持会明确提示「暂不支持」，不会静默失败

明确不做的事

不托管原片

影序没有「把照片传到我们服务器」的路径。原片只在你选择的本地磁盘或个人网盘里。

不自动删片

所有质量判断都是候选，删除必须人工确认，并保留可撤销记录。

不做修图

不提供调色与渲染流水线；RAW 只读取与预览，不改原文件。
