首次打开说明

macOS

当前为 ad-hoc 签名（没有 Apple Developer ID），Gatekeeper 会拦截。二选一：

  • 在「应用程序」里 右键 → 打开，再点「打开」
  • 或执行 xattr -d com.apple.quarantine /Applications/影序桌面开发版.app

若提示「已损坏」，通常是下载未完整或隔离属性未清除，可重新下载并按上面第二条处理。

Windows

安装包未做代码签名，SmartScreen 会提示「Windows 已保护你的电脑」。

  • 点「更多信息」→「仍要运行」
  • 安装模式为当前用户，不需要管理员权限

企业环境若被策略拦截，请联系管理员按哈希加白。

未签名 ≠ 已签名发布。我们不会把 ad-hoc 说成正式签名；正式证书到位后会在版本说明里单独写。

校验下载完整性

每次发布都会附带 SHA256SUMS。下载后本地比对，避免传输损坏或被替换：

macOS / Linux

shasum -a 256 -c SHA256SUMS

Windows（PowerShell）

Get-FileHash .\影序桌面开发版_xxx_x64-setup.exe -Algorithm SHA256

更新策略

当前版本不包含应用内自动更新。新版本以 GitHub Release 形式发布，需手动下载安装。自动更新要等签名密钥与更新清单校验链就绪后才会开启——在那之前不会有静默更新。
