隐私政策

你的影像，不离开你的设备

最后更新：2026-10-25。本政策描述影序桌面端与本站点如何处理数据。原则很简单：能不收集就不收集，能留在本机就留在本机。

1. 桌面端处理什么

  • 只读你的来源目录：影序扫描文件名、大小、修改时间与文件身份标识，用于生成备份计划。原片不会被修改、移动或删除。
  • 本地数据库：任务、副本清单、校验结果、索引与缩略图保存在应用数据目录的 SQLite 数据库中，不离开本机。
  • 缩略图：在本机生成，去掉 EXIF 后存储；导出交付包时才随包提供。
  • EXIF：只读取机型、镜头、拍摄时间、ISO、光圈、快门、方向等拍摄字段。不保留 GPS 坐标，不保留原始 EXIF 块。

2. 什么会上传

  • 默认不上传任何原片或缩略图。视频只在本机分析，帧数据不离开设备。
  • 只有在你主动开启并逐项确认时，才会同步任务元数据（任务名、状态、统计）到你自己的云端或模型服务。
  • 网盘上传（百度/夸克）在你授权后由本机直接对目标服务发起，影序不中转、不留存你的原片。授权令牌只保存在操作系统的凭据库（macOS 钥匙串 / Windows 凭据管理器 / Linux Secret Service），不写入数据库、日志或仓库。

3. 本站点（官网）

  • 本站是纯静态页面，没有后端、没有埋点脚本、没有广告 SDK，也不设置追踪 Cookie。
  • 下载页会向 api.github.com 请求公开的 Release 列表以显示真实版本号与校验值。该请求由你的浏览器直接发出，GitHub 会看到你的 IP，适用 GitHub 自身的隐私政策。

4. 我们不做的事

  • 不建立用户画像，不做行为分析，不向第三方出售或共享数据。
  • 不在你不知情的情况下上传、备份或分享任何影像。
  • 不把「配置成功」当成「数据安全」来宣传——安全与否以校验结果为准。

5. 数据留存与删除

  • 所有本地数据都在你的磁盘上，删除应用数据目录即彻底清除。
  • 副本与来源文件始终由你掌控：影序没有远端副本可供我们删除。
  • 解绑网盘会撤销并删除本机令牌，历史结果记录保留以便追溯（不含令牌）。

6. 儿童与敏感数据

影序面向个人影像管理，不面向儿童单独设计。若你处理含他人肖像或敏感场景的素材，请自行确保取得合法授权。

7. 变更与联系

政策如有实质变更，会在版本说明与仓库中同步记录。问题请通过支持页反馈。
