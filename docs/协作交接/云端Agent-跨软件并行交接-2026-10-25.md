## 3. 重要修复与平台差异

1. CloudBase 新业务表默认赋予 anon SELECT、authenticated 写权限。已在任何真实用户数据写入前通过 v2 撤销并启用 RLS。后续新增表和 RPC 必须在同一迁移中限制默认授权，不能只依赖 FastAPI owner 过滤。
2. HTTP 云函数必须监听 9000，启动脚本为 `scf_bootstrap`，Python 使用绝对路径 `/var/lang/python311/bin/python3.11`。
3. 包内 `third_party/` 是 Linux x86_64/Python3.11 wheels，不能上传 macOS 虚拟环境。Linux 完整锁为 `cloud-service/requirements.linux.lock`；通用开发锁另保留。
4. 官方 docs 的 HTTP API body `{path,method}` 方式对本项目原生 FastAPI 未路由到目标端点；已验证的方式是 URL 后缀路径 + `webfn=true`。
5. 新路由 API 拒绝修改系统默认域名，也拒绝 `domain:"*"`。两次创建都失败，未产生路由；当前使用平台 HTTP API，不继续重复试错。
6. PostgreSQL DescribeDBInstanceAttribute 可读；DescribeAccounts 返回 CAM 权限拒绝。不要把环境 API Key 当成自动解除 CAM 权限的凭证。当前转向官方 PostgREST 业务访问，不扩大权限。
7. 默认 Node/npm 安装自身报错；使用 Homebrew PATH 可运行 CLI：`PATH=/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin npm exec --yes --package=@cloudbase/cli -- tcb ...`。CLI 版本3.8.9。
8. `--cwd` 配合 `--dir .` 曾解析到仓库根目录并在缺少 bootstrap 时停止。实际部署必须用函数包工作目录与绝对 `--dir`；不要上传整个项目。
