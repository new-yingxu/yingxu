## 二、核心缺口

**没有任何一条分支同时具备「完整 UI + 本机 Agent + 原生云登录 + 原生百度上传」**：

- L1 有 UI/Agent，缺云登录与云服务能力；
- L2 有 UI/Agent/云服务路由（`/v1/auth/session/exchange` 已存在），缺 `cloud_auth.rs`（原生登录）
  与 `baidu.rs`/`BaiduPanel.vue`（原生百度）；
- L3 有原生登录+百度，但 UI 是 421 行草稿、无本机 Agent。

两线直接 merge 会产生 87 处 add/add 冲突（我 10-28 实测），必须按能力移植，不能整体合并。
