## 4. 你需要知道的接口（前端接入用，不需要等我）

后端已就绪，你可以直接把 `DesktopApi` 接上。请求格式不变：`{requestId, version:1, method, params}`。

| 方法 | 参数 | 返回要点 |
|---|---|---|
| `capabilities.get` | — | `rawPreview` / `rawFormats` / `videoMetadata` / `videoFrameExtraction` / `netdiskProviders`，用来灰化入口 |
| `library.analyze` | `{mediaId}` | 按类型自动分派（RAW / 照片 / 视频） |
| `library.analyzeRaw` | `{mediaId}` | `rawFormat/previewSource/thumbnailAvailable`；`fullDecodePerformed:false` |
| `video.probe` | `{mediaId}` | `metadata.video.{durationMs,width,height,fps,videoCodec,bitrateBps,createdAt}` |
| `video.analyze` | `{mediaId, extractFrames?}` | `frameSource` ∈ `embedded_cover` / `ffmpeg_keyframe_seek` / `ffmpeg_keyframe_then_nearest` / `ffmpeg_stream_seek` / `frame_extractor_unavailable`；恒 `framesUploaded:false` |
| `backup.scanReport` | `{source}` | `{files, skipped[], scanned, skippedTotal, skippedTruncated}`；`reason` ∈ `unportable_name`/`symlink`/`unreadable` |
| `netdisk.providers` | — | `approval: pending\|local_only`、`authorized`、`realUploadAvailable` |
| `netdisk.beginAuth` | `{provider}` | `authorizeUrl`（用系统浏览器打开）、`expiresInSeconds` |
| `netdisk.authPoll` | `{provider}` | `state: pending\|ready\|error` —— **轮询这个**，别自己解析回调 |
| `netdisk.completeAuth` | `{provider, code?}` | `code` 可空（后台回调已保存） |
| `netdisk.enqueue` | `{provider, mediaId}` | 先核本地 SHA-256；`localVerified:true`；**排队 ≠ 已上传** |
| `netdisk.tasks` | — | `chunksDone/chunksTotal/verifiedRemote/state` |
| `netdisk.run` | `{taskId, baseUrl?, maxConcurrency?, maxMbps?}` | 失败分片返回 `resumable:true`；远端哈希一致才 `completed` |
| `netdisk.cancel` | `{taskId}` | 绝不写"已上传" |
| `netdisk.unbind` | `{provider, confirmed}` | `historyKept:true` |

三条语义请务必照做：

1. `approval != "approved"` → 显示"资质未获批"，**不要**渲染"连接"按钮。
2. 上传进度只用 `chunksDone/chunksTotal`，别用百分比反推"已完成"。
3. 失败要把 `error.code` 透出（`RAW_PREVIEW_NOT_FOUND`、`VIDEO_CONTAINER_UNSUPPORTED`、`NETDISK_NOT_APPROVED`…），
   不要统一吞成"失败"。

## 6. 环境坑（我踩过，省你时间）

1. macOS 默认 `MacOSX27.sdk` 与当前 `ld` 不兼容 → `SDKROOT=.../MacOSX15.4.sdk`。
2. `grep` 被工具链换成 toybox → `cargo tauri build` 打 dmg 会在 `bundle_dmg.sh` 挂；用系统 PATH 或 `scripts/make-dmg.sh`。
3. GitHub release 资产常被代理 502，但 `api.github.com` 可达 → 走 `assets/{id}` + `Accept: application/octet-stream`。
4. macOS `/var` 是符号链接 → 测试路径要 `canonicalize()`，否则 safe-dir 检查直接拒绝。
5. 网络会整段不可用，下载类任务要分批重试。
