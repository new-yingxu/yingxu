## 3. 网盘上传（骨架）

### 改动

`backend/core/src/netdisk.rs`、`backend/scripts/mock-netdisk-server.py`、`backend/scripts/verify-media.py`。
方法经 `ext.rs` 暴露：`netdisk.providers / beginAuth / completeAuth / authPoll / unbind / enqueue / tasks / run / cancel`。

实现：PKCE(S256) + loopback 回调（后台线程收 code，UI 轮询 `authPoll`）；token 只进系统凭据库
（macOS Keychain / Linux secret-tool / Windows DPAPI，均经 stdin 或 env 传值，不进 argv/日志/SQLite）；
分片上传 + 分片游标落盘续传；入队与执行前各核一次本地 SHA-256；逐文件独立结果；取消不留「已上传」。
任务状态存 `应用数据目录/netdisk/tasks/*.json`（避开 SQLite schema 迁移，减少与另一会话冲突）。

## 4. RAW 分析

### 改动

`backend/core/src/raw.rs`（新文件，未改 `media.rs`）。方法：`library.analyzeRaw`、`library.analyze`。

实现：按文件头识别容器（TIFF LE/BE、BigTIFF、CR3/BMFF、RAF）；预览提取三路优先——
TIFF IFD（IFD0/IFD1/SubIFD，`0x0201/0x0202` 与 `0x0111+0x0117+compression 6/7`）→ RAF 头 84/88 字节偏移
→ 通用流式 JPEG 扫描（256 KiB 块，只记偏移，不整文件入内存）。每个候选都要真解码通过才采用。
EXIF 只留机型/镜头/拍摄时间/ISO/光圈/快门/焦距/方向，**GPS 与原始 EXIF 块不入库**；
容器读不到就退到预览内部的 EXIF。出口复核 fingerprint 保证原片只读。

### 验证

```
[PASS] RAW 走预览提取（未做全解码）
       {'format': 'tiff_le', 'previewSource': 'tiff_ifd', 'fullDecode': False, 'sourceReadOnly': True}
[PASS] RAW 产出 512px 缩略图   maxEdge 512
$ cargo test raw:: → 6 passed（TIFF 内嵌预览、CR3 扫描兜底、RAF 头偏移、无预览显式报错、端到端只读、非 RAW 拒绝）
```

### 未完成 / 阻塞

- **没有真实机型样本**。交接要求的「佳能/尼康/索尼/富士/松下 各 3–5 个真实样本，记录成功率/耗时/内存峰值」**未做**——当前证据全部来自构造样本（TIFF + 内嵌 JPEG）。
- 未选型 LibRaw（LGPL/CDDL 与 +5–10 MB 体积）。当前是纯 Rust 的「内嵌预览」路线，不做显影。
- BigTIFF、HEIF 容器显式返回 `RAW_UNSUPPORTED`。
- CR3 走通用 JPEG 扫描，理论上能命中预览，但**未经真实 CR3 验证**。

## 5. 视频分析

### 改动

`backend/core/src/video.rs`（新文件）。方法：`video.probe`、`video.analyze`。

实现：纯 Rust 解析 MP4/MOV box（moov→mvhd/trak→tkhd/mdia→hdlr/minf→stbl→stsd/stsz），
得时长/分辨率/旋转/fps/编码/码率/创建时间/音轨；`moov` 超 96 MiB 拒绝；整文件不入内存。
抽帧：10%/50%/90% 各 1 帧，外挂 `ffmpeg`（或 `YINGXU_FFMPEG`），单帧 20 s 超时、512 宽、
超时/缺失记 `frame_extractor_*` 而不崩。质量信号复用照片的曝光/清晰度算法，输出「待复核」。
无任何网络调用，帧只落本机缩略图目录（返回体里 `framesUploaded: false`）。

### 验证（真实 4K MP4，ffmpeg 现场生成）

```

[PASS] 4K 视频抽帧成功   {'frameSource': 'ffmpeg_stream_seek', 'frames': 3}
[PASS] 帧数据不出本机
子进程内存峰值 596.7 MiB（含 ffmpeg 子进程；RPC 进程本体不解析像素）
$ cargo test video:: → 4 passed（元数据、非 BMFF 拒绝、moov 缺失、端到端）
```

### 未完成 / 阻塞

- 抽帧**强依赖本机 ffmpeg**；没有时只出元数据（`frame_extractor_unavailable`），不冒充成功。
- 只支持 MP4/MOV；MKV/AVI/MTS 明确 `VIDEO_CONTAINER_UNSUPPORTED`。
- 未接入 ffprobe 随包分发（体积 +30–80 MB，许可 LGPL）——当前用系统 ffmpeg，未随包。
- 关键帧优先（`-skip_frame nokey`）未做，现在是就近非关键帧。
