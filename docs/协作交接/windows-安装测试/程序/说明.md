# 这是便携版（对照用），安装包在 `安装包/`

双击 `影序桌面开发版_0.2.0-draft.1_x64-portable.exe` 直接运行，
不需要安装、不写注册表、不需要管理员权限。删掉这个 exe 即等于"卸载"。

## 为什么还留一份便携版

安装包已经出了（`安装包/影序桌面开发版_0.2.0-draft.1_x64-setup.exe`）。便携版留在这里是为了
**拆问题**：如果安装版启动失败，先用便携版跑一次，就能判断是「安装器/权限」还是「程序本体」的问题。

## 便携版与安装版的差异（测试时要区分）

| 项 | 便携版 | 安装版 |
|---|---|---|
| 安装/UAC/安装路径 | 不适用 | 有 |
| 开始菜单快捷方式 | 无（双击 exe） | 有 |
| 卸载 | 删除 exe | 控制面板卸载 |
| 应用数据目录 | 同样在 `%APPDATA%\app.yingxu.desktop.next` | 同左 |

`README-测试说明.md` 里 TC-02/TC-12 已按便携版改写，其余用例照常执行。

## 运行前提

- Windows 10 1809+ / 11，x64
- WebView2 运行时（Win11 自带；Win10 多数已随 Edge 安装）。若启动白屏，先装
  [Evergreen 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。
- 首次运行 SmartScreen 会拦：**更多信息 → 仍要运行**（未签名，属预期）。
