确认这个包在**真实 Windows 机器**上能装、能开、能干活、能干净卸载；把每一步的实际结果填回本目录的
`测试记录表.md`，遇到失败请附截图与 `collect-env.ps1` 的输出。

## 1. 前置条件

- 一台可正常联网的 Windows 10 1809+ / Windows 11 x64 机器（物理机优先，虚拟机也可，请注明）。
- WebView2 运行时（Win11 自带；Win10 多数已随 Edge 安装，可用 `collect-env.ps1` 确认）。
- 至少两块盘：系统盘 + 一块可写的第二磁盘/U 盘（用于备份目的地，容量 ≥ 2 GB）。
- 准备 5–10 个小素材：几张 JPG/PNG、一个 MP4 或 MOV、可选一个 RAW（`.cr2/.nef/.arw`）。
  没有 RAW 可以跳过 TC-08，不影响其余结论。
- **不要**在存有唯一一份重要资料的目录上做测试；TC-05 会复制文件（不会删除来源）。

## 2. 安装（TC-01 ~ TC-03）

1. 解压本包到任意目录（建议非系统盘，例如 `D:\yingxu-test\`）。
2. 先校验安装包，与 `安装包/SHA256SUMS.txt` 比对：

   ```powershell
   Get-FileHash .\安装包\影序桌面开发版_0.2.0-draft.1_x64-setup.exe -Algorithm SHA256
   ```

   应为 `f64eb69c9109acdcec5d3269266177f28d0d5e70ceb48a147e48c25dc2c19140`；对不上请停手并回传实际值。
3. 双击安装。SmartScreen 提示「Windows 已保护你的电脑」→ **更多信息 → 仍要运行**。
4. 安装模式是**当前用户**，不应弹 UAC；若弹了 UAC 请记录（说明与预期不符）。
5. 安装完成后从开始菜单启动「影序桌面开发版」。

> 若安装器本身跑不起来（闪退/报错），改用 `程序/` 里的便携版继续测其余用例，
> 并把安装失败的截图与报错原文单独回传——这属于必须修的阻塞问题。

放行步骤详见 `首次打开说明.md`。

## 3. 测试用例

**填写方式**：每条填「结果（通过/失败/阻塞）＋ 实际观察 ＋ 截图文件名」。失败不用修，如实记录即可。

| 编号 | 用例 | 步骤 | 期望 |
|---|---|---|---|
| TC-01 | 安装包完整性 | `Get-FileHash` 比对 `安装包/SHA256SUMS.txt` | 一致（应为 `f64eb69c9109acdc…`） |
| TC-02 | 静默安装与权限 | 正常双击安装 | 不要求管理员/UAC；装到 `%LOCALAPPDATA%\影序桌面开发版`；开始菜单出现条目 |
| TC-03 | 首次与二次启动 | 双击启动 → 关窗到托盘 → **再次双击 exe** | 首次出主窗口；二次启动应**唤回已有窗口**且无闪退（此前版本的 panic 已修复，见交付包内说明） |
| TC-04 | 托盘与后台 | 关闭窗口 | 进程不退出，托盘有图标；点托盘可恢复窗口 |
| TC-05 | 只读扫描来源 | 选一个素材目录作为来源 | 能列出文件数/总量；**来源目录内文件不被修改**（记录前后修改时间） |
| TC-06 | 备份到第二磁盘 | 选第二磁盘为目标，勾选校验，执行 | 复制完成；逐文件 SHA-256 校验通过；进度条与统计一致 |
| TC-07 | 暂停/继续/取消 | 复制中途暂停 → 继续；另起一次任务中途取消 | 暂停后进度停住、继续能接上；取消后不留下"已完成"的假记录 |
| TC-08 | RAW 预览 | 若有 RAW，索引后分析 | 能出缩略图与机型/拍摄时间；无预览时提示"暂不支持"而不是静默失败 |
| TC-09 | 视频分析 | 选一个 MP4/MOV 分析 | 能读出时长/分辨率；有 ffmpeg 才有缩略图，没有时只出元数据并说明 |
| TC-10 | 历史与报告 | 打开历史，导出 JSON/CSV 报告 | 报告内容与实际任务一致；同名文件不覆盖 |
| TC-11 | 网盘入口 | 打开网盘相关入口 | 明确显示"资质未获批/不可用"，不出现假的"已连接" |
| TC-12 | 卸载与残留 | 设置 → 应用 → 卸载 | 卸载成功；程序目录清空；用户数据目录仍在（需手动删）；无残留服务/开机项 |

## 4. 需要特别留意的 Windows 特有问题

- **盘符与中文路径**：素材目录用中文名、盘符用 `D:\` 这种普通路径即可；若用了 `\\?\` 长路径或网络盘，
  请单独记录，程序明确不支持网络共享路径。
- **杀软拦截**：未签名 exe 可能被 Defender/第三方杀软拦。请记录拦截提示原文与厂商名。
- **权限**：若素材在 `C:\Program Files` 或需要管理员才能读的目录，记录报错码。
- **高 DPI**：系统缩放 125%/150% 时窗口是否错位、是否横向滚动。
- **中英文路径混合**：文件名含 emoji 或特殊字符时是否报 `INVALID_PATH_ENCODING`。

## 5. 采集环境信息（失败时必附）

在包目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\collect-env.ps1
```

会在同目录生成 `env-<主机名>-<时间>.txt`，包含系统版本、安装目录、进程状态、日志尾部与安装包哈希。
**不含**素材内容与个人文件路径以外的隐私信息。

## 7. 安全与边界

- 程序不会上传你的素材；视频只在本机分析，帧不出本机。
- 备份只复制、不移动、不删除来源；删除类操作需要二次确认且可撤销。
- 请勿用真实客户素材测试；用样本即可。
- 发现凭据泄露、路径穿越、校验绕过等安全问题，请单独私信，不要写进公开记录。
