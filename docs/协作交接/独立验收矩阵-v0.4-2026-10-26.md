# 影序 v0.4 独立验收缺口矩阵（2026-10-26）

> 范围：将 v0.4 功能/技术草稿对照 WorkBuddy 交付自述与 R3/R5/R6/R7 证据，独立整理当前可支持的验收结论及后续门槛。
> 性质：只读验收文档；本轮未改产品代码，未重跑测试、构建或发布。测试用例存在不代表本轮通过；WorkBuddy 报告与本线亲自观察分开记录。
> 项目框架仍为未确认草稿，以下矩阵用于安排验收，不代表 v0.4 功能已整体完成。

## 结论摘要

- **已观察到的原生闭环：** R3 在 macOS 本地调试宿主中完成系统选目录、扫描/预检、取消无写入、确认复制、SHA-256 对照、报告读取与导出；使用隔离合成样本，不是发行包。
- **已观察到的隔离 HTTP 闭环：** R5 通过本机 FastAPI 与隔离 SQLite 验证客户端同步协议，但身份固定为开发 owner/device，不能证明真实账号、CloudBase 或多账号切换。
- **模型同意流程：** R6 的 UI 与客户端检查使用合成响应，没有请求真实模型供应商或计费；同意/尝试记录未跨重启持久化。
- **前端与宿主边界：** R7 在 macOS 原生调试宿主观察到扫描/索引跳过项和只读网盘状态。视频重复分析出现“第一次 3 帧、第二次 0 帧”；后续修复由 R8 处理，本矩阵不重复改码，也不把修复算作已验收。
- **Windows：** 当前没有 Windows x64 VM 的安装、启动、单实例、托盘或退出回归证据。已有安装包哈希和源代码静态检查不等于 Windows 运行验收；详见[独立验收核查](独立验收核查-2026-10-26.md)。

### Agent 当前结论

- **本地已具备：** LangGraph 基本编排、owner-scoped 最近任务只读工具、本机 Ollama 真实调用/只读工具循环、会话持久化与 checkpoint 基础，以及 0.7.1/0.7.2 function-context 候选包的本地证据。
- **尚未形成完整桌面 Agent：** 本地文件检索/打开与确认式文件操作没有端到端实现；0.7.2 候选包已有 renew，但桌面续期/过期后重新认证路径未闭环；R11 短会话 desktop adapter 未闭环；真实模型中断后 checkpoint 恢复和最新桌面发行包均未验收。
- **外部项保持独立：** CloudBase HTTP/生产身份、schema11 线上部署、邮箱/短信/微信、远端模型和 Windows x64 原生验收均待外部条件。109 项/11 个 skip 是此前 0.7.1 回归记录；0.7.2 的 115 项、104 passed、11 skipped 来自协调报告，本线未重跑，11 个 CloudBase skip 不并入通过数。
