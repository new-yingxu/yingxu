## 4. 会话 B 的任务清单

1. **adapter 骨架**：`createTauriApi(): DesktopApi`，内部统一走 `invoke('backend_request', {request: {requestId, version:1, method, params}})`。
2. **格式层**：Rust 返回字节数/时间戳 → 前端展示串（`1.2 GB`、`2 小时前`）；反向不做（前端不往 Rust 传格式化串）。
3. **目录选择**：`backup.scan()` 前端无参，需先 `invoke('select_directory', {purpose:'source'})` 拿到绝对路径再调 `backup.scan`。
4. **两阶段任务**：`backup.start(payload)` → `backup.preview` 取 `planId` → 用户确认 → `jobs.start{planId,confirmed:true,idempotencyKey}`。
5. **进度**：监听 `local-job-updated` 事件更新任务卡；`jobs.detail` 轮询兜底。
6. **云端方法**：`auth.*`、`agent.*`、`account.*`、`settings.connectProvider` 返回明确未连接状态，不造假会话。
7. **降级**：非 Tauri 环境（浏览器预览）自动回退 `createMockApi()`，保证 `pnpm dev` 仍可看界面。
8. **联调验收**：临时目录跑通一次完整备份，报告可导出。
