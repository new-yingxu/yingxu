## 必测项

请按 `windows-安装测试/README-测试说明.md` 完整填写 `测试记录表.md` 或 `.csv`，至少覆盖：

1. 安装包完整性、当前用户安装和卸载。
2. 首次启动、关窗最小化到托盘、托盘恢复、再次启动单实例唤回和显式退出。
3. 只读扫描来源；来源文件内容和修改时间不变。
4. 复制到第二磁盘并逐文件 SHA-256 校验；进度/数量/报告一致。
5. 复制中暂停、继续、取消；失败时不留下假成功。
6. 中文路径、DPI 缩放和文件权限错误。
7. 有样本时测 RAW 预览和 MP4/MOV 元数据/分析；无样本标跳过并说明原因。
8. 网盘入口显示实际资质状态，不得显示假连接或假上传成功。

来源、目标权限不足、空间不足、拔盘/目标消失等异常可作为扩展项；测试时仅使用隔离目录，不对真实素材做转移/删除。
