# 本地后端状态（本会话维护）

更新时间：2026-10-25，北京时间。当前里程碑：**本地后端 B1 草稿**。不是整个后端全量完成或前后端已连接。

## 已实现并验证

- Rust + SQLite/FTS5：只读来源扫描/索引、预检计划、明确确认、1–8 个本地目的地持久队列、SHA-256、同哈希跳过/异内容编号、不覆盖、暂停/继续/取消、失败目标重试、逐文件/目标结果及速率。
- 文件安全：本地路径/嵌套/符号链接校验，Unix 目录句柄及 no-follow 读写，独占临时副本与原子提交，源/目标身份和来源变化检测。进程中断后只清理已登记且身份相符的临时副本，任务暂停等待继续。
- 历史搜索/改名、白名单设置/命名预设、JSON/Markdown/TXT/CSV 报告导出、健康审计、按可信副本恢复。恢复/交付重复请求幂等，相异请求不能复用键。
- 校验后转移：短时一次性 token、再次确认、逐文件重新校验、来源移入可撤回目录、可撤回且不覆盖。**当前不释放卡空间，不永久删除、不提供系统废纸篓清空。**
- 交付包：独立队列、逐文件校验、JSON manifest、SHA256SUMS 和本地 HTML 联系表；校验失败不登记为完成。
- 受限照片解码、选定 EXIF 相机/拍摄时间及来源、最长边 512px 无 EXIF JPEG 缩略图、曝光/清晰度候选、人工复核。阈值未校准，不自动判好或清理。
- 本地 API v1 + JSON-lines CLI；Tauri 主窗口 IPC、原生目录选择授权、单 worker、托盘、关闭窗口后台运行/退出暂停。宿主已在 Mac ARM64 编译构建；**未启动图形生命周期验收**。
- sync.outbox 投影现有 sync-event-v1；默认不含路径。关闭路径同步会停发旧路径事件并新建脱敏事件，避免同一事件 ID 改写内容。没有真正发送/ack/云端连接。
