## 5. Agent/云端会话的实施范围

### A. FastAPI 服务与数据层

- 按框架建立 HTTPS REST 与 WebSocket；云端不打开桌面磁盘路径。
- 账号、登录方式关联、设备/会话撤销、任务摘要、Agent 会话、预设、可选缩略图及同步偏好。
- 账号删除、用户删除同步数据、分页、幂等、失败重试、离线/最后同步时间、结构化错误码。
- CloudBase 作为框架既定身份/存储方向；先核对真实区域、认证渠道、数据库模式、访问权限和删除能力。若现有条件不支持，给出具体证据和替代方案供用户决定，不擅自迁移平台或增加收费服务。
- 云端数据库必须按已认证账号隔离。通过 account/device/session 验证资源归属，不能使用请求体里的 ownerId 作为权限依据。
- 提供环境变量模板、迁移/初始化脚本、可复现本地启动方式与 API 文档；配置缺失时返回明确未就绪状态，生产环境不得自动切换假认证。

### B. 登录与设备身份

- 手机验证码、邮箱验证码、微信网站应用扫码登录按框架同时规划。
- 验证码限流、防重放、短时过期；微信 OAuth 校验 state/nonce，服务端换 code；桌面回跳票据短时且一次性。
- AppSecret 和第三方 token 不进入前端、Git、明文 SQLite 或日志；桌面仅取得适合桌面客户端的短期影序会话凭据。
- 设备注册、撤销、刷新/过期与账号注销数据清理；账号绑定/合并不得仅凭相同昵称或邮件显示名判断。
- 手机端由朋友维护；核对其实际身份服务与 UID 规则，输出兼容协议，不修改其移动端代码。

### C. Agent 服务

- 首先做有限工作流和白名单工具。LangGraph 是框架候选，可用固定状态机先实现明确流程；不要让模型承担复制或长时上传 worker。
- 文本检索与状态查询可直接完成，返回文件 ID、匹配原因、数据来源、同步时间和可用性。
- 有副作用的改名、移动、上传必须返回具体对象/目标/影响的提议，经桌面本地再次预检和用户确认后才执行。
- 提议 ID、来源会话、有效期、执行状态和结果持久化；拒绝/过期/重试/取消均有可追溯状态。
- 不能执行任意 Shell、eval 或模型生成的系统命令；工具入参必须校验，工具返回和用户资料当作不可信内容。
- 模型供应商、BYOK 密钥、费用与可用区域单独验证；无配置时明确不可调用，不用模拟回复宣称模型接入完成。

### D. 个人网盘官方授权协作

- 只做百度、夸克官方允许且实际获批的个人用户授权，不逆向网页/客户端 API。
- 云端方负责官方资格核查、需要服务端密钥的 OAuth/回调和接口文档；桌面方负责本地文件读取、验证后的持久上传任务和数据流。
- 原片只从桌面直接发给用户授权的网盘；不能通过影序云端做原片中转或持久保存。
- 只有本地副本 SHA-256 成功后才可排队上传。逐目标结果独立，部分失败只重试失败目标。
- 夸克个人网盘上传权限尚未验证。接口未确认时记录明确阻塞点，不编造 scope、回调和上传端点。

### E. 部署、运行与交付

- 验证适合现有 CloudBase 环境的 FastAPI 部署方式、WS、运行时限、日志、费用和资源额度。优先满足现有低成本/免费方向，涉及新增付费或绑定新外部权限先说明具体条件。
- 配置 HTTPS、必要 CORS 来源白名单、短期鉴权、健康/就绪检查、日志脱敏、Secrets、最小权限、限流、持久化、备份和恢复。
- 给出部署与回滚步骤、版本/commit、镜像标识、实际服务地址、健康结果、身份与数据读回证据。
- 本地测试、部署配置成功、云端部署成功、真实账号可用和前后端联调成功分别记录，不能相互替代。
- 移动端构建、桌面打包/签名和原 GitHub Pages 下载站改版不属于云端会话范围。

## 6. 双方对接约定

### 6.1 本地/云端边界

```text
Vue 桌面 UI → Tauri IPC → Rust/SQLite/本地 worker → 本地磁盘/用户网盘
                           ↓ 持久 outbox（按同步开关过滤）
                  HTTPS/WS → FastAPI → CloudBase
                                   ↕
                          云端 Agent / 手机只读同步资料
```

备份必须能完全离线运行。云端暂时不可用、未登录或 Agent 失败，不得阻断本地复制/校验。

Agent 生成提议，不直接执行桌面路径。任何云端发来的操作都要在桌面重新校验文件 ID、允许目录、设备、任务、有效期和具体影响。

### 6.2 同步事件

以 `contracts/sync-event-v1.schema.json` 为双方开发基线：

```json
{
  "schemaVersion": 1,
  "eventId": "example-event-id",
  "deviceId": "example-device-id",
  "sequence": 1,
  "eventType": "job.snapshot.v1",
  "occurredAt": "2026-10-25T11:00:00Z",
  "payload": {
    "jobId": "example-job-id",
    "name": "示例任务",
    "state": "success",
    "phase": "success",
    "files": 1,
    "bytes": 1024,
    "progress": 100,
    "targets": [{"id":"example-target-id","state":"success","copied":1,"skipped":0,"verified":1,"failed":0}]
  }
}
```

上面是协议样例，不是真实任务或已部署接口调用结果。

本地 SQLite outbox 已有事件序号、设备 ID、任务 ID 和最小摘要字段；当前尚无网络发送 adapter。原始 Rust Job 含文件指纹/路径，不允许直接上传整对象。双方在联调时实现显式 envelope 投影。

云端对同一 owner 下的 eventId 及 deviceId+sequence 双重去重，拒绝同键不同正文；持久化后确认实际接受的事件。WS 断线不丢本地任务；先快照、后增量，缺口重拉。设备属于哪个账号由验证后的身份决定。

### 6.3 供云端方落实的接口清单

以下是建议路由清单，尚未实现或部署；云端会话可以在不改变语义的前提下将确切路径写入自己的 OpenAPI。

| 接口分组 | 最低能力与桌面所需输出 |
|---|---|
| `/healthz`、`/readyz` | 版本、启动/依赖就绪状态，不泄露配置内容 |
| `/v1/auth/*` | 登录会话/验证码/微信回调/票据交换/刷新/退出 |
| `/v1/devices/*` | 设备注册、列表、撤销、在线与最后同步时间 |
| `/v1/sync/events` | 批量幂等入库、已接受 ID、拒绝项与重试条件 |
| `/v1/sync/snapshot` | 当前账号权威快照、游标、分页与删除标记 |
| `/v1/ws` | 短期鉴权、增量事件、重连游标，禁止手机桌面控制 |
| `/v1/agent/sessions/*` | 对话持久化/删除/分页与工具步骤 |
| `/v1/agent/turns` | 当前端来源与设备绑定的 Agent 请求及流式响应 |
| `/v1/agent/actions/*` | 提议/拒绝/过期/本地执行回执；不能用“云端已确认”代替本地授权 |
| `/v1/account/sync-preferences` | 记录/Agent/缩略图/路径开关，关闭路径时处理既有字段 |
| `/v1/account/data` | 删除同步数据、导出与账号注销级联删除 |
| `/v1/providers/{baidu,quark}/*` | 仅在官方能力获批后实现的授权状态与需要服务端处理的 OAuth 流程 |

请求追踪 ID、错误码和可重试标志请统一；至少区分未登录、会话失效、设备撤销、权限不足、需要授权、确认过期、不支持、幂等冲突、限流与暂时不可用。

### 6.4 Agent 工具和确认

初始提议见 `contracts/agent-proposal-v1.schema.json`。其中 `origin` 由认证上下文绑定，不能信任请求正文。文件使用稳定 ID，目标使用桌面本地不透明授权 ID；云端不能用任意绝对路径控制桌面。

建议执行状态：`proposed → awaiting_local_confirmation → queued → running → succeeded/failed`，另有 `declined/expired/unsupported`。用户没有本地确认时不得进入 queued/running。

读工具先落地：`search_media`、`get_backup_job`。写工具逐步接入：预览/改名、预览/移动、百度/夸克上传。转移来源移除单独由本地二次确认流程处理，不作为通用云端工具；废片清理仅能触及已确认的隔离副本并移入系统废纸篓，不动原片。

## 7. 必须保留的隐私与产品规则

- 原片不进入影序云端。允许同步任务、对话、最长边约 512px 的压缩缩略图和可关闭的路径/电脑名称；路径与缩略图各有独立开关。
- 精确 GPS/EXIF、第三方 token、API Key 不同步到业务事件/Agent 日志/前端。
- 云端视觉只对用户逐张选择并逐次确认的照片开放，桌面直接调用获准供应商；首版视频分析在本地，不借此默认发送视频/抽帧。
- 手机 Agent 只查云端同步数据和管理手机自己的备份，不能控制桌面任务、桌面写文件或清理桌面素材。
- 多目标独立，云盘失败不改变本地副本成功；任何失败都不能据此删除来源。
- 注销删除账号云端数据，不得删除用户本机媒体；旧事件重放不得使已删除云端资料复活。
- 质量指标是待样本验证目标，不能在部署说明中写成已达到。

8. `docs/协作交接/云端Agent状态.md`：当前实现、检查证据、部署状态、授权等待项、下一步和本地会话需要的信息。

不能用 HTTP 200 代替账号隔离、真实验证码/扫码或业务持久化验收。桌面联调要等待本地 IPC/adapter 和云端实际契约就绪后由双方对照完成。

## 10. 双方同步与启动顺序

- 另一会话：读取资料 → 盘点已有账号和代码 → 建立云端服务/Agent 协议与检查 → 核实官方依赖 → 实际接入/部署 → 更新状态和联调资料。
- 本会话：继续 Rust/SQLite 本地后端、文件安全与恢复检查，补齐本地接口入口/宿主，再接入已确认前端。
- 每个阶段更新各自状态文件。改变字段时先追加协议变更请求，避免双方各改一套状态枚举或参数名。
- 需要另一会话处理的问题由用户转交，或在用户明确指定目标会话并授权发送后使用会话消息工具。本交接尚未向其他会话发送，也没有替用户创建新会话。

交接包只包含框架、协议、状态和前端领域类型；不含令牌、账号凭据、真实照片、数据库、node_modules、Rust target 或整段聊天。
