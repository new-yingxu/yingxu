## 本地后端接口边界

- 当前源码路由包括：`GET /healthz`、`GET /readyz`、设备注册/撤销、`POST /v1/sync/events`、`GET /v1/sync/snapshot`、同步偏好、Agent action/turn/receipt 与 `/v1/ws`。
- 手机 origin 的工具权限仍按白名单限制；写入仅产生待本机确认提议，不让云端直接控制桌面文件。
- 事件身份由可信签名身份解析，不接受请求正文提供 owner。同步的路径/缩略图偏好必须落实到历史数据清理与删除游标，不能只依赖界面开关。
- 本地源码和隔离模拟不代表线上 URL、真实身份或生产数据库验收。
