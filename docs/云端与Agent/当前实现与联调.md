# 影序云端与 Agent 当前实现

更新时间：2026-10-28

## 已有实现

- `cloud-service/app/`：FastAPI 服务、显式认证模式、SQLAlchemy 租户/设备/同步事件/Agent 提议/同步偏好模型。
- 复用 `contracts/` 的两个 v1 schema，服务端逐条校验；同账号下 `eventId` 与 `(deviceId, sequence)` 双重幂等，重放正文不一致返回 `IDEMPOTENCY_CONFLICT`。
- 用户身份从验签 JWT 的 `sub`/`device_id`/`origin` 取得，不读取请求正文中的 owner。设备须先注册，撤销设备不能同步。
- 手机 origin 只允许 `search_media`、`get_backup_job`。写入工具只落 `awaiting_local_confirmation` 提议；回执不授予桌面文件操作权限。
- 查询仅检索已同步的任务摘要，不调用模型，不读取本地路径或原片。
- 关闭路径同步时剔除既有事件中的 `source`、`paths`。云端同步偏好不改变桌面本地数据。
- 生产配置拒绝 SQLite、开发认证与空 CORS 白名单。认证默认禁用并失败关闭。

## 尚未完成 / 未验收

- Python 3.14 本地隔离环境依赖安装与 API 烟测已通过；详见 `cloud-service/evidence/smoke-2026-10-25.md`。Smoke 不代表生产验收。
- JWT claim 与 CloudBase/移动端实际身份未对接，验证码、微信 OAuth、账号绑定、会话刷新/撤销未实现。
- 数据模型尚未做最终 CloudBase 数据库类型的迁移和持久化验证；不得使用 SQLite 部署生产。
- WebSocket 已实现首帧验权、初始快照和增量轮询；本地开发 token 下完成初始快照连接烟测。真实 JWT、重连游标、长时间断线和撤销行为仍待真实身份与生产环境验证。
- Agent 当前是检索已同步备份记录的有限服务端工作流，无 LLM、工具执行器或真实媒体检索。
- 账号数据删除/导出、会话、缩略图、快照分页与删除游标尚未实现。
- CloudBase 环境、数据库、域名、部署 URL、运行日志和费用均未确认；没有部署成功证据。
- 百度网盘真实 OAuth 与上传尚未实现或验收；夸克已从产品范围移除。

## 本地后端会话需要消费的信息

- REST 路由和 OpenAPI 初步清单：`GET /healthz`、`GET /readyz`、`POST /v1/devices/register`、`GET /v1/devices`、`POST /v1/devices/{device_id}/revoke`、`POST /v1/sync/events`、`GET /v1/sync/snapshot`、`PUT /v1/account/sync-preferences`、`POST /v1/agent/actions`、`POST /v1/agent/turns`、`POST /v1/agent/actions/{action_id}/receipt`、`/v1/ws`。
- 事件请求与 Agent 提议沿用两个 v1 schema；目前不改变既有 schema。
- 以上仅为本地源码接口，不代表可访问的云端 URL。联调前需双方核对 OpenAPI、鉴权 claims、错误码、分页和事件删除语义。

## 2026-10-28 网盘范围与百度接入状态

- 用户将网盘范围收敛为仅百度网盘个人账号；本轮桌面前端和本地核心不再提供夸克 Provider。
- 当前 `backend/core/src/netdisk.rs` 是本地 mock 传输骨架，不是百度真实 OAuth/上传实现。源码闸门仍为 `pending`；未核实 API scope/上传权限前，`netdisk.beginAuth` 与上传入队均失败关闭，不返回占位授权 URL。
- 桌面 UI 仍是 MockDesktopApi 演示，百度入口明确显示待接入，不会执行真实授权或上传。
- 用户截图确认百度网盘应用“影序YINGXU桌面”已上线，且仅限个人场景使用；控制台登记的本机 OAuth 回调为 `http://127.0.0.1:8765/callback`。截图未展示该应用实际获批的网盘 API scope/上传能力，因此不能据此将真实 Provider 解锁。
- AppKey、SecretKey、SignKey 已在截图中以明文显示。它们不写入代码、文档、日志、记忆或 Git；待本轮开发结束后应统一轮换。桌面发行包不能安全隐藏应用 Secret，真实 code/token 交换必须由已部署且受控的服务端持有 Secret。
- 当前工作树未接入 CloudBase 管理 MCP，`tcb` CLI 也不可用；因此尚不能安全配置服务端 Secret、部署 token 交换端点或检查线上运行状态。浏览器自动化在百度网盘页面被当前会话策略阻止，不能代替用户授权流程。
- 百度开发者中心的公开接入资料支持 `basic,netdisk` scope 和 OAuth/分片上传流程概览，但可访问资料较旧或属于社区内容；权限以当前应用控制台/官方答复为准。官方开放平台入口 `https://pan.baidu.com/union/document/entrance` 当前无法由网页读取工具访问。
