# 影趣 Agent 智能影像资料管理软件｜功能框架

> 状态：讨论稿 v0.1（2026-10-25）
> 本文是功能范围的唯一维护文档。后续确认或修改时直接更新本文件，不另建同主题版本。
> 当前只整理框架；此处的功能描述不代表已经实现或通过验收。

## 1. 产品定位与范围

影趣 Agent 面向摄影师及影像资料管理场景，管理照片从导入、备份、校验、整理、检索、质量筛选到跨设备查看和受控操作的流程。它是“影像资料管理 Agent”，备份可靠性和原片安全优先于自动化程度。

AI 分类：**L3 Agent 驱动型应用为主，L2 影像分析为辅**。Agent 能理解目标、查询本地资料、调用受限工具并检查结果；过曝、模糊、重影识别属于影像分析。实际文件复制、改名、移动、上传仍由确定性工具执行，不能由模型直接拼系统命令。

### 本会话负责范围

- 当前优先开发 Windows 与 macOS 桌面端前端和相应验收。
- 产品功能框架覆盖全产品；Android/iOS 的界面和原生实现由另一位开发者负责，本轮不展开其实现细节。
- 桌面与移动端共用账号、任务协议和状态定义；手机远程查看的是桌面实际执行的任务，不代表手机可以在桌面离线时继续读取电脑磁盘。
- 产品官网负责产品介绍、下载入口和版本说明，与桌面应用界面分开维护。

## 2. 核心用户流程

1. **首次设置**：选择资料库位置、默认备份目的地、命名规则、隐私与云同步设置；可跳过非必要账号登录，具体策略待确认。
2. **导入**：用户连接相机卡、移动硬盘或选择已有目录；应用检测来源与可读空间，显示文件数量、总容量和格式概况。
3. **制定备份计划**：选择一个或多个目标；预览目录结构、命名规则、冲突处理、重复文件策略和预计空间。
4. **执行任务**：后台队列逐文件复制、计算 SHA-256 并按策略校验；可暂停、恢复、取消，显示进度、速率、剩余量和失败项。
5. **整理与质检**：读取照片元数据，生成分类/命名建议，识别疑似过曝、失焦、重影或损坏文件；用户可预览并选择应用建议。
6. **追溯与检索**：搜索文件和任务记录，打开原文件或所在目录，查看每个目的地的结果和校验状态。
7. **远程查看与 Agent 操作**：已登录的移动端查看桌面任务状态；Agent 根据用户权限查找文件、打开文件，或提出改名/移动/上传操作并在必要时要求确认。

## 3. 功能模块与优先级

| 优先级 | 模块 | 功能范围 | 关键边界 |
|---|---|---|---|
| P0 | 桌面主界面 | 首页、导入/备份入口、当前任务、近期记录、状态与错误提示 | 先确定信息架构和空/错/忙/完成状态，再做视觉细化 |
| P0 | 本地备份任务 | 选择来源与一个目标、后台执行、暂停/恢复/取消、进度/速率/剩余量、错误重试 | 任务状态需可恢复；窗口隐藏不能停止任务；退出应用需明确告知任务影响 |
| P0 | 多目的地与校验 | 选择多个独立目的地；记录每个目标的复制和校验结果；任务结束生成追溯报告 | 每个目标独立显示成功/失败；不得把部分成功显示为全成功 |
| P0 | 文件清单与哈希 | 为每个文件记录大小、时间、格式、SHA-256 等必要信息；识别字节完全相同的重复文件 | SHA-256 适合校验和精确重复判定，不等于视觉相似检索；默认不自动删除原片 |
| P0 | 任务报告 | 生成可读文本报告，含来源/目的地、时间、数量/容量、速率、校验结果、跳过/失败项及原因 | 任务失败也生成报告；路径和照片元数据可能敏感，用户可选择本地保存与分享 |
| P0 | 托盘与后台体验 | 关闭窗口后隐藏到系统托盘/菜单栏；点击图标恢复窗口；显示任务概况和快捷操作 | 运行中的任务继续；退出命令与隐藏窗口区分；系统状态栏展示能力按平台设计 |
| P1 | 智能命名与目录整理 | 按拍摄时间、相机、项目等字段提出规则；执行前预览；处理重名与目标冲突 | 默认复制后整理，不覆盖源文件；批量改名支持撤销/回滚清单 |
| P1 | 影像质量筛选 | 识别疑似过曝、模糊、重影、损坏或无法解码的文件，给原因、置信度和预览 | 首版作为筛选/标记建议；不自动“修复”或删除原片，修图能力另行确认 |
| P1 | 本地影像库与搜索 | 建立文件索引，按文件名、目录、日期、相机与可检索元数据筛选 | 本地索引可重建；文件移动/外置盘离线需显示“暂不可用”而不是误报丢失 |
| P1 | 实时任务共享 | 桌面推送任务状态；手机查看速率、进度、阶段、最近错误和最后同步时间 | 依赖桌面在线并联网；重连后从服务端快照恢复，离线展示最后状态和时间 |
| P1 | 受控 Agent | 对话查找、打开文件/目录；预览后改名、移动；查询备份状态 | Agent 只调用类型化白名单工具；改动文件、覆盖或外传前显示明确对象并确认 |
| P2 | 百度网盘上传 | 用户授权后选文件/目录上传，显示进度，支持暂停/取消/失败重试，记录网盘结果 | 先验证开放平台应用资格、OAuth 范围、目录与分片限制；令牌不得写入源码或公开仓库 |
| P2 | 账号与设备 | 微信、手机号、邮箱登录与账号绑定；设备列表、会话和授权管理 | 确认账号合并规则、手机号短信地区、邮箱验证/找回及不同端授权体验后实施 |
| P2 | 官网与下载 | 产品能力、系统要求、下载入口、版本/更新说明、隐私与支持信息 | 下载包版本必须与发布清单匹配；不把官网展示当成应用发布或安装验收 |

优先级是当前建议，实施时根据已有软件代码、用户反馈和实际设备测试调整。

## 4. Windows/macOS 桌面页面草图范围

首轮前端可先建立以下导航与页面状态，数据由明确标注的 mock/fixture 驱动，后续接入真实本地接口：

- **首页**：开始备份、当前任务摘要、近期任务、空间与连接状态。
- **新建备份**：来源、多个目的地、命名/重复策略、校验选项、预计容量、执行前确认。
- **任务详情**：整体与分目的地进度、当前阶段、速率、剩余时间估算、可暂停/恢复/取消、逐项错误。
- **影像资料库**：搜索和筛选、质量标签、元数据摘要、打开文件/目录。
- **任务记录与报告**：历史任务、报告预览/导出、校验失败定位。
- **Agent**：对话、工具调用过程、匹配文件卡片、操作确认卡片、执行结果。
- **账号/设备/设置**：登录状态、设备同步、隐私、目的地、命名规则、后台行为。

所有页面至少定义 loading、empty、error、offline、permission-denied、partial-success 和 completed 状态。Mock 数据不能伪装成实时任务。

## 5. 影像安全与操作规则

1. **原片保护**：默认只读来源；不在源目录执行改名、覆盖、删除或修图。
2. **备份结果如实表达**：多个目的地逐个展示；网络/磁盘/权限错误给出路径与可执行恢复建议。
3. **重复判定分层**：SHA-256 相同表示文件字节相同；相同照片重新编码或元数据不同可能哈希不同。视觉相似/连拍相似需单独的感知哈希或模型能力，列为后续可选项并保留人工复核。
4. **质量标签可解释**：展示判定理由和预览；置信度低时只提示复核。过曝信息已丢失时不能承诺无损恢复。
5. **危险操作先确认**：删除、覆盖、批量移动、外部云上传、分享报告、账号解绑需展示目标和影响；可以撤销的操作生成变更清单。
6. **最少云端数据**：备份中的原始照片默认留在用户设备/目的地；跨设备同步只上传完成远程展示所需的任务与设备状态，文件内容和完整路径是否同步需用户设置与单独评估。

## 6. 增量开发与每项验收

采用“小功能完成即验证”的循环；任一阶段出现失败或结果不清楚，先停在该阶段修复和复验，再进入下一阶段。测试范围按改动选择，不把未做的设备/云端验收写成通过。

| 阶段 | 小交付 | 验收标准 |
|---|---|---|
| 0 | 读取旧软件资料、确认可复用部分和现有技术栈 | 新仓库结构与技术选择有依据；不搬入未经审查的大段旧代码 |
| 1 | 桌面导航、首页、新建备份、任务详情静态界面 | Windows/macOS 窗口布局可用；所有空/忙/错/部分成功状态能浏览；mock 明确标识 |
| 2 | 前端任务状态适配层和假任务流 | 状态转换、进度、暂停/恢复/取消按钮可通过可控 fixture 验证；协议与 UI 分离 |
| 3 | 接入本地备份纵向切片 | 在临时照片目录复制到一个目的地；显示进度；重启后任务记录一致；SHA-256 校验可追溯 |
| 4 | 后台/托盘行为与报告 | 隐藏窗口后任务继续、图标可恢复、退出行为清楚；报告展示实际逐目标结果 |
| 5 | 多目的地、命名和精确重复检测 | 每目标结果独立；命名预览无静默覆盖；原片不被改写；精确重复依据 SHA-256 |
| 6 | 影像质量提示与 Agent 本地工具 | 用明确样本检查误判；定位/打开安全；改名/移动前确认并可回查；模型不直接执行任意命令 |
| 7 | CloudBase 账号、跨设备进度、百度网盘与官网 | 分别验证正式 OAuth/账号绑定、在线/断线重连、网盘授权和上传、官网版本指向；每项独立验收 |

Windows 与 macOS 的行为差异分别验收。UI 单元/状态测试不能代替目标系统的实际窗口、文件权限、托盘、挂起/退出和安装包测试。
