# 影序 YINGXU 移动端功能框架 v1.0（草稿）

> 状态：待产品确认，供移动端实现与评审使用。本文只定义 Android/iOS 手机端；桌面端仍由 Windows/macOS Tauri 应用负责。移动端由 Expo 项目负责人实现。
> 对齐基线：桌面功能框架 v0.4 草稿、技术框架 v0.4 草稿，以及用户已确认的跨端边界。文档不代表功能已实现或通过设备验收。

## 1. 产品定位与边界

手机端是影序的随身查看与手机素材备份入口，和桌面端共用个人影序账号、设备清单、备份记录及 Agent 会话。手机端不保存摄影原片到影序自有云端，也不远程控制桌面电脑的备份任务。

| 能力 | 手机端 v1.0 | 桌面端 | 边界 |
|---|---|---|---|
| 账号登录与跨端资料 | 登录、管理本机设备、查看已同步记录和会话 | 登录、产生桌面任务及会话 | 个人账号；不提供团队/公司网盘模式 |
| 桌面任务 | 查看在线状态、进度、速度、阶段、结果、错误和最后同步时间 | 扫描、创建、暂停/恢复/取消桌面任务 | 手机只读；不向桌面发起控制命令 |
| 手机素材备份 | 扫描授权的手机照片/视频，预检、确认后备份到本机可访问目标或用户授权的百度/夸克网盘 | 备份电脑相机卡、磁盘和移动盘内容 | 写入目标前明确展示目标、命名、容量与覆盖/跳过规则；OS 不允许的目标不显示为可用 |
| 媒体与质量分析 | 浏览本机素材、任务结果；分析能力分阶段实现 | 照片和视频质量分析、废片隔离 | v1.0 不承诺手机端与桌面端模型指标完全一致；云端复核逐张确认 |
| Agent | 查询账号已同步数据、解释记录、管理手机自己的备份 | 查询和操作当前桌面允许访问的本地素材 | Agent 工具按设备隔离，不可经云端绕过设备边界 |
| 原片与路径 | 不同步原片；桌面完整路径仅供查看且可关闭 | 原片留在电脑/用户选定目标 | 手机不能用桌面路径打开文件或操作电脑 |

## 2. 导航与页面

建议采用底部主导航：**概览、备份、照片、Agent、我的**。桌面端和手机端复用品牌色、任务状态词和核心数据字段；手机针对单手操作、窄屏及系统权限调整布局。

### 2.1 登录与设备

- 提供手机号短信验证码、邮箱验证码、微信扫码登录；扫码流程由系统浏览器/安全回调完成，资质和服务端配置未就绪时显示“暂不可用”，不得模拟成功。
- 展示当前登录账号、已登录手机和桌面设备、桌面在线状态及最近同步时间。
- 支持退出、移除/撤销设备授权、账号数据导出和注销入口。注销须告知会删除账号云端同步数据，不删除用户设备上的原片。

### 2.2 概览

- 汇总最近备份、今日处理量、待处理提醒、最近使用设备和桌面连接状态。
- 桌面任务卡片显示：电脑名称、阶段、已完成/总数或字节数、速度、预计剩余时间（服务端提供且可信时）、目标结果、最近错误及最后更新时间。
- 离线或同步中断时明确显示缓存数据和时间；不可把旧进度伪装成实时数据。
- 提供“开始手机备份”入口，创建的任务归属当前手机，不会作用于桌面。

### 2.3 手机备份

1. 用户授权访问照片/视频后，扫描可访问素材并显示数量、总大小、类型及无法读取项。
2. 预检目的地空间、网络、登录授权和文件名冲突；插入/选择素材本身不会自动开始写入。
3. 用户选择目标（手机系统可访问的文件夹/外部介质，或个人百度网盘、夸克网盘）、命名/目录规则并预览结果。
4. 用户确认后创建任务；展示排队、上传/复制、校验、完成、部分完成、失败和可重试状态。
5. 使用 SHA-256 做内容校验；同名同内容跳过，同名不同内容保留双方并为新文件增加序号，不覆盖已有文件。
6. 百度/夸克各自显示授权和结果；一家失败不抹去另一家或本地已成功结果，只重试失败目标。
7. 支持暂停/继续/取消手机自己的任务、后台后返回恢复状态、失败原因和重试。后台运行时长受系统策略约束，界面必须说明可能被系统延后或中止。

### 2.4 照片与记录

- 浏览本机已授权素材、手机备份记录、桌面同步记录及单条任务报告；筛选日期、设备、任务状态和媒体类型。
- 桌面任务仅显示同步上来的记录与 512px 最长边压缩缩略图；缩略图自动同步，可在设置关闭。显示电脑名称和完整路径的开关可独立关闭，路径只读。
- 不从缩略图推断原片仍在线；注明缩略图/原片的来源设备和最近同步时间。
- 桌面废片隔离区可查看分类与缩略图。手机可发起“请求桌面 Agent 处理”的文本建议，但 v1.0 不生成桌面动作命令；清理动作只由有素材访问权限的桌面端完成，且只处理隔离副本、经用户确认后移入系统废纸篓。
- 手机端质量筛选如上线，照片/视频分开标注模型版本、置信度和可解释原因；初始量化目标为照片与视频分别评测：候选精确率 ≥98%、可用素材误报 ≤1%、明显废片召回 ≥80%。达标前标为实验/辅助建议，不自动删除。

### 2.5 Agent

- 同步桌面和手机的 Agent 会话历史、工具动作摘要和结果；会话列表按设备及时间区分，可在手机继续对话。
- 手机 Agent 可查询：账号云端已同步的备份历史、设备状态、已同步缩略图、路径（若用户开启）和手机本机备份信息。
- 手机 Agent 可管理手机自己的备份任务；涉及选择照片、写入目标、上传、改名、移动或清理时，先展示对象、目标与影响，再由用户确认。
- 手机 Agent 不可启动、暂停、恢复、取消或修改桌面任务，不可在桌面上改名/移动/删除文件，也不可调用任意 shell/系统命令。
- 本地模型为默认免费选项；可选云端模型由用户自带 Key 并显示用量。Key 通过系统安全存储保护，不上传影序同步服务。将照片发送给云端模型须逐张选取并逐次确认；视频不默认发送云端。

### 2.6 网盘与设置

- v1.0 网盘范围仅百度网盘、夸克网盘个人账号。展示官方授权状态、空间/配额（接口允许时）、上传任务和撤销授权入口。
- 只有在用户授权官方开放平台/API 的范围内接入；接口、资质或权限未核实前标记“待接入”，不通过抓取网页、共享 Cookie 或模拟登录实现。
- 设置提供浅色/深色/跟随系统、缩略图同步开关、桌面完整路径与电脑名称同步开关、通知、网络偏好、权限说明、隐私说明、数据导出/删除和账号注销。
- 备份记录与 Agent 对话同步为必需项；用户手动删除后按账号范围删除。注销时清除云端同步数据。网络恢复后按本地待同步队列补传。

## 3. 跨端信息与同步规则

### 必须同步

- 账号与设备授权关系、桌面备份记录和逐目的地结果、任务报告/可追溯日志摘要。
- Agent 用户/助手文本、最终答复、工具动作摘要和结果（不含密钥、访问令牌）。
- 用户同意开启时同步最长边约 512 px 的压缩缩略图；可关闭。
- 用户同意开启时同步桌面电脑名称和完整本地路径；手机仅查看，可关闭。

### 不同步

- 原始照片/视频、网盘访问令牌、模型 Key、未授权精确 GPS/EXIF、桌面可执行命令和完整本地索引数据库。
- 手机端绝不把桌面控制请求写入普通同步事件队列；云端只转发明确定义的数据同步事件，不做代理式远程桌面控制。

### 一致性与隐私

- 任务状态分别记录设备、任务、目的地、阶段、进度、错误、更新时间和事件序号；以服务端确认的最新快照为准。
- 断线显示上次成功同步时间；重连后先取快照，再补齐缺失事件。重复请求必须幂等，不因重试重复写入或重复创建任务。
- 路径、缩略图和会话均按个人敏感资料处理：传输加密、账号/设备隔离、最小权限、撤销设备后拒绝后续访问。用户可删除；注销触发云端级联删除并反馈完成状态。

## 4. v1.0 交付顺序

| 阶段 | 范围 | 完成标准 |
|---|---|---|
| P0 视觉与基础 | Expo 页面骨架、导航、主题、登录态、设备/空状态 | Android 与 iOS 尺寸适配；错误、无权限、离线和加载状态齐全 |
| P1 只读跨端 | 账号设备、桌面任务快照/实时增量、历史、Agent 会话与缩略图 | 手机只读桌面；断网、重连、重复事件与最后同步时间可验收 |
| P2 手机备份 | 素材权限、扫描预检、目标和命名预览、确认、进度、校验、暂停/重试 | Android/iOS 真机分别验收前后台、存储权限、断点续传、空间不足和进程被杀恢复 |
| P3 Agent 与云盘 | 手机本地备份工具、逐项确认、百度/夸克个人授权及失败重试 | 使用正式授权/测试账号验证；没有 API/密钥/审批时停在清晰的待接入状态 |
| P4 质量与隐私收尾 | 质量建议、隐私控制、删除/注销、导出 | 质量指标按媒体类型报告；数据删除有可观察结果；不自动删除原片 |

## 5. v1.0 验收红线

- 手机任何操作都不会改变桌面任务状态；桌面离线时仍能正确查看最后同步快照。
- 未确认目标、命名和写入规则前，不开始备份或上传。
- 只对用户授权的媒体和目的地执行操作；失败、部分成功、重试均保留清晰记录。
- 不把缩略图/路径同步等同原片备份，不把排队任务宣称为实时进度。
- 不把 Expo 后台任务当作持续运行保证；根据 Android 与 iOS 真机结果明确可支持的后台能力。
- 不宣称未获得授权的微信登录、百度网盘/夸克网盘连接或云端模型已可用。
