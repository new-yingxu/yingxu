# 首次打开说明（随安装包一起分发）

影序当前是**未签名测试版**。系统会拦截一次，放行后功能完整可用。

## macOS（.dmg）

1. 双击 `.dmg`，把「影序桌面开发版」拖进「应用程序」。
2. 在「应用程序」里**右键点图标 → 打开 → 再点「打开」**。
3. 若提示「已损坏」或「无法验证开发者」，打开终端执行：

   ```bash
   xattr -d com.apple.quarantine "/Applications/影序桌面开发版.app"
   ```

   然后重新双击启动。

> 这是 ad-hoc 签名（`codesign -s -`）的正常现象，不是文件损坏。等 Apple Developer ID 证书到位后会换成正式签名 + 公证。

## Windows（.exe）

1. 运行安装包，SmartScreen 提示「Windows 已保护你的电脑」时点 **更多信息 → 仍要运行**。
2. 安装模式为**当前用户**，不需要管理员权限，装到 `%LOCALAPPDATA%\影序桌面开发版`。
3. 企业环境被策略拦截时，可按安装包 SHA-256 加白（校验值见 Release 页的 `SHA256SUMS`）。

## 校验下载是否完整

```bash
shasum -a 256 -c SHA256SUMS        # macOS / Linux
Get-FileHash .\<安装包> -Algorithm SHA256   # Windows PowerShell
```

哈希对不上说明下载损坏或被替换，请重新下载，不要继续安装。

## 数据与卸载

- 应用数据（数据库、缩略图、上传任务）在应用数据目录内，卸载后请手动删除以彻底清除。
- 原片永远在你自己的磁盘上，影序不会移动或删除它。
- 卸载不会删除你已生成的任何备份副本。
