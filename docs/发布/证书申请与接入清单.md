# 签名方案 · 全免费（2026-10-26 定稿）

> **决策记录**：Windows 与 macOS 都走**免费签名**；安卓端与苹果端（PWA/原生）由另一位同学负责，
> 不在本文范围。付费证书路线已废弃，压缩成文末附录备查。

## 1. 两端的现状（就是免费方案，无需再买任何东西）

| 平台 | 方式 | 配置位置 | 用户第一次打开时看到什么 |
|---|---|---|---|
| macOS | **ad-hoc 签名**（`signingIdentity: "-"`，含 hardened runtime） | `backend/tauri-host/tauri.conf.json` → `bundle.macOS` | Gatekeeper 拦截：「无法验证开发者」→ 右键打开 / 系统设置里允许 |
| Windows | **不签名**（NSIS 产物无 Authenticode） | `bundle.windows.nsis` | SmartScreen：「Windows 已保护你的电脑」→ 更多信息 → 仍要运行 |

放行的具体步骤（截图级）见 `docs/发布/首次打开说明.md`，该文件随安装包一起放进 Release。

**实测**（2026-10-26）：macOS `.app` 为 `Signature=adhoc, flags=0x10002(adhoc,runtime)`，从 dmg
安装后可正常启动；`spctl -a` rejected 属预期。Windows 安装器 3,864,384 字节未签名，SmartScreen
会拦，属预期——这正是交给测试同学验证的一部分（用例 TC-01 前的放行步骤）。

## 2. 免费方案的三个已知代价（都接受了）

1. **首次打开多一步放行**（上表）。不影响功能，只影响第一印象——用「首次打开说明」补。
2. **自动更新关闭**。无签名就无法做 Tauri 更新包签名校验，`latest.json` 恒
   `updater_enabled: false`、`signature` 为空（`scripts/gen-latest-json.py` 已按此输出）。
   用户升级 = 去官网下载页拿新版（下载页自动列最新 Release 与 SHA-256）。
3. **杀软误报概率略高**。未签名 exe 更容易被 Defender/第三方杀软盯上，测试包里专门有
   「记录杀软拦截原文」的用例，收集到案例再针对性处理（加白名单申请等，均免费）。

## 3. CI 不需要任何签名 secrets

`.github/workflows/release.yml` 全程不引用签名凭据：macOS 任务在非本机环境会自动落 ad-hoc，
Windows 任务直接出未签名 NSIS。**不需要配置 `APPLE_CERTIFICATE` / `TAURI_SIGNING_PRIVATE_KEY` 之类的 secret。**

## 4. 验收口径（免费方案做到什么程度算合格）

| 项 | 命令 / 方法 | 期望 |
|---|---|---|
| macOS 包完整性 | `codesign --verify --deep --strict <app>` | valid on every packet（ad-hoc 也必须过） |
| macOS 镜像 | `hdiutil verify <dmg>` | checksum VALID |
| Windows 安装器 | `Get-FileHash` 比对 Release 里的 `SHA256SUMS` | 一致 |
| 放行可用 | 按首次打开说明走一遍 | 能装、能开、能卸载，无功能差异 |

## 附录：如果以后想升级到付费签名（当前不做）

原付费路线的要点压缩如下，仅备忘：

- **macOS**：Apple Developer Program（US$99/年）→ Developer ID Application 证书 + `notarization` 公证 →
  Gatekeeper 不再拦。配置点：`bundle.macOS.signingIdentity` + CI 里
  `APPLE_CERTIFICATE` / `APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID` secrets。
- **Windows**：OV（¥1–3k/年）主体可见但 SmartScreen 需积累信誉；EV（¥3–6k/年，硬件 token）立即免拦；
  Azure Trusted Signing（US$9.99/月）需企业满 3 年。配置点：`bundle.windows.certificateThumbprint` +
  `digestAlgorithm`，CI 加对应 secrets。
- 触发再看的信号：用户反馈「放行步骤劝退」明显、或杀软误报率高到影响分发。
