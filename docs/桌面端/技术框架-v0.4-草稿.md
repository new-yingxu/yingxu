## 2. 总体架构和调用边界

- 桌面 UI：Vue 3 + TypeScript + Vite；本阶段先做可走查的交互前端，演示数据必须与真实服务接口隔离并有明显标识。
- 桌面宿主：Tauri 2 / Rust，管理窗口、权限、菜单栏/托盘、IPC、生命周期和更新入口。
- 本地核心（前端确认后再实施）：Rust 有界异步 worker；检测卡/移动盘后只自动扫描预检，不自动写入。用户确认目标和命名预览后才开始复制、SHA-256 校验、命名、转移、暂停/恢复/取消、重试和报告。
- 本地数据：SQLite + FTS5，保存索引、任务队列、目标结果、历史、报告索引和待同步事件。
- 影像适配：照片/视频容器元数据、LibRaw RAW 元信息/预览、图片/视频缩略图与解码分层；sidecar 等关联文件作为素材保留。质量分析分别提供照片和视频流程，不支持解码的文件仍备份并标记未分析。
- 云端：FastAPI HTTPS REST + WebSocket，处理账号设备、任务摘要、授权命令、Agent 入口和同步；不直接打开桌面路径。
- Agent：LangGraph 作为多步工作流候选；先固定有限流程和白名单工具，不成为备份队列。
- 云端身份/存储：腾讯云开发 CloudBase；业务数据库模式、API 访问和区域待验证。原片不经过影序云端；仅按用户设置同步任务/对话、最长边约 512px 缩略图、电脑名称和可关闭的完整路径。
- 移动端由用户朋友使用 Expo 负责；桌面侧后续只定义并提供账号/设备/任务协议，不接手移动端源码和构建。
- 网盘范围仅百度网盘，采用个人用户授权；不支持 NAS/局域网共享目标。仅在本地备份 SHA-256 校验成功后，按用户勾选网盘创建持久上传任务。百度官方 API 权限、额度和授权方案须先验证；网站继续使用既有 GitHub Pages 下载站。

UI 调本机能力只走 Tauri IPC；UI 与云端走 HTTPS/WebSocket，仅同步用户允许的数据。云端永远不直接访问本机文件系统。

## 4. 本地任务、文件安全和数据模型

### 4.1 建议数据实体

- media_items：本地文件 ID、路径/卷 ID、格式、大小、拍摄和修改时间、相机、GPS、SHA-256、可用状态。
- jobs：任务类型、来源、总体状态、创建/开始/结束时间、进度、检查点、错误摘要。
- job_targets：每个目的地的状态、复制/跳过/校验/失败计数、重试和错误。
- job_items：每文件来源、目标、计划操作、哈希、阶段、重试、失败原因和完成时间。
- naming_templates：字段、顺序、自定义值及版本。
- reports：本地报告格式、位置、摘要及生成状态。
- outbox_events：设备 ID、任务 ID、递增序号、最小同步负载和同步状态。
- audit_events：Agent/用户操作、确认人、对象、旧值/新值、目标及结果。

SQLite 放系统用户数据目录；迁移有版本和可恢复备份；索引可重建。任务表是恢复依据，不能以内存队列作为唯一状态。

### 4.2 复制与转移安全

1. 预检来源/目标、写入权限、空间、路径嵌套、符号链接和目标介质。
2. 不先删除已有目标。使用排他创建写入临时副本，避免覆盖或误清理其他任务文件。
3. 完整写入并刷新后，流式计算源/目标 SHA-256；一致才标记校验成功。
4. 将临时副本以目标文件系统支持的安全方式提交，最终状态重新校验。
5. 转移来源前先向用户展示转移计划；目标副本 SHA-256 校验成功后，再重检源文件身份/大小/时间/哈希并进行第二次明确确认。只有目标确认成功且来源未变化，才移除来源。
6. 失败、取消、拔盘、空间不足、权限错误、校验不匹配或崩溃都保留来源，并产生明确可恢复状态。
7. 每个目标独立排队、重试和结束；某个目的地失败不重做已确认成功的目标。
8. 目标同名文件先比较 SHA-256：相同内容跳过；不同内容保留现有文件，并给新文件加序号，不覆盖。网盘端须按其官方 API 能力验证冲突处理方式。

统一任务状态：排队、扫描、预检、复制、校验、待上传、上传中、暂停、取消、部分完成、失败、成功。重新打开应用后从 SQLite 检查点恢复，必要时重算哈希；未验证成功不得显示成功。

## 5. 搜索、影像与报告

- SQLite FTS5 用于文件名、用户备注和可索引文本；日期、大小、设备、地点、状态使用结构化字段与索引。FTS5 不等于图像语义搜索。
- SHA-256 流式分块读取，不将大文件整体载入内存；可先按文件大小筛候选再比较哈希。
- 感知哈希/模型相似单独记录算法版本、阈值、相似分组和复核状态，不冒充精确重复。
- EXIF/元数据读取需保留字段来源；无法读取拍摄时间时可回退文件时间，但必须标记回退来源。
- RAW 用 LibRaw 相关适配层读取支持的元信息/预览；普通位图预览用独立解码库。按品牌、机型、RAW 编码和色彩空间维护验证样本表。
- 质量分析输出过曝、模糊、重影、损坏等候选及理由/置信度。需要修图时生成独立派生图，不覆盖原片；不可承诺恢复剪切丢失的数据。
- 每个任务提供 Markdown/TXT 可读报告，并可导出 JSON/CSV；记录任务 ID、版本、来源、目的地、时间、数量/容量、速率摘要、逐目标校验、跳过/失败原因。

## 6. 实时同步、账号和 CloudBase

- REST 获取任务快照、历史、设备、设置和幂等操作结果；WebSocket 传输实时增量和授权命令。
- 桌面先写本地任务/outbox，再异步发云端；断线期间本地备份继续。事件使用设备 ID + 任务 ID + 递增序号幂等接收。
- 移动端先取权威快照再订阅增量；断线后按最后序号补齐，缺口时重拉快照，显示最后同步时间。
- 云端同步账号、设备、备份记录、Agent 会话、最长边约 512px 的压缩缩略图及完整本地路径/电脑名称；缩略图、路径/电脑名各自可关闭，手机对桌面路径只读。原片、访问令牌和精确 GPS/EXIF 不上传影序云端。
- 用户可手动删除同步数据；注销账号时一并删除账号云端数据。保留到用户删除为止。实现需核验 CloudBase 访问控制、传输/静态加密、级联删除和备份清除能力。
- 移动 Agent 的工具集只允许查询云端同步资料和操作手机本地备份；不发出或执行桌面本地任务命令。桌面 Agent 可在桌面本地权限内操作。
- 登录同时提供手机短信验证码、邮箱验证码和微信扫码。正式实现前核对 CloudBase/身份服务的区域、短信及邮件渠道、微信网站应用授权、账号绑定、FastAPI 访问数据库的路径、费用、备份和权限。
- 账号合并/解绑、注销、设备撤销和数据导出单独设计；注销清除云端同步数据但不得删除本机素材。

## 7. Agent、本地工具桥与个人网盘

- LangGraph/固定状态机只管理意图到工具的流程；备份和大文件上传由持久任务执行。
- 类型化工具候选：search_media、get_backup_job、open_item、preview_rename、rename_item、preview_move、move_item、upload_baidu。
- 云端 Agent 不拥有任意本地路径访问能力；在线桌面桥根据登录设备、文件 ID、允许目录、任务状态和权限再次检查。
- 查找/预览可直接完成；改名、移动、来源删除、废片清理和上传必须先展示具体文件、目标和影响，再由用户确认；操作进入审计。手机 Agent 不调用桌面本地工具。
- 只接百度网盘官方允许且已获批的个人账号授权、OAuth scope、回调、刷新、额度及上传协议，不逆向或模拟网页 API。必须先完成本地复制与 SHA-256 校验，再将用户勾选的网盘分别写入持久上传队列，展示速度/进度/结果；某一家失败时本地仍标成功，整体显示部分完成，并只重试失败目标。
- 密钥和令牌不得写进仓库、明文 SQLite、日志或前端存储；使用 macOS Keychain、Windows Credential Manager 或经验证的安全存储。
- 桌面 Agent 支持免影序账号 BYOK：默认可选本机 Ollama；DeepSeek 与通义千问使用固定官方 HTTPS Chat Completions 端点（DeepSeek 默认 `deepseek-flash`，通义千问默认 `qwen-plus`，模型标识可编辑）。本机 Tauri 宿主把用户 Key 保存在系统钥匙串/凭据管理器，通过一次性标准输入管道交给隔离 sidecar，不放入前端持久状态、环境变量、SQLite、日志或 CloudBase。只支持受控供应商和模型标识，不允许用户提交任意网络端点。保存时不发测试请求，避免产生意外用量；第一次对话时才由用户逐轮确认并验证 Key。
- 远端推理只改变模型服务位置：LangGraph、SQLite、白名单媒体/任务查询和文件执行留在桌面本机。每轮先显示供应商、模型、查询和数据范围，用户确认后才发送；原片、完整本地路径与 GPS 不发送。模型可收到查询文字和最多 10 条最小化索引摘要；模型不得直接执行操作，文件操作仍由本机权限桥另行确认。禁止静默回退或自动重试；不确定结果保留原轮次，避免重复计费。
- 影序账号和 BYOK 是两条独立通道：不登录也可用本机 Agent 与自带 Key 云模型；影序登录仅用于启用 CloudBase 账号同步/设备管理。BYOK Key 属于用户与模型供应商之间的凭据，不发送给影序服务。
- 分发客户端无法可靠隐藏内置应用密钥；若任一网盘流程要求客户端密钥，先确认官方允许的桌面授权模式或由受控服务端代理方案。百度网盘 API 可用权限及实现路径均待验证，授权未通过前不宣称接入完成。

## 8. 桌面生命周期和托盘

- 关闭主窗口默认隐藏到系统托盘/菜单栏，任务继续；点击图标恢复主界面。
- Windows 托盘提供状态和打开窗口；macOS 菜单栏显示图标/短状态并展开轻量任务面板。详细速率、剩余时间和目标状态放在面板/主窗口。
- 显式退出与隐藏窗口区分；任务运行时退出前显示暂停/终止影响并执行可恢复收尾。
- 进度/速率使用平滑采样，剩余时间标注估算；任务失败/结束可通知，避免高频刷新。

| 恢复与健康审计 | SQLite 增加 restore_jobs、audit_runs、replica_checks；以源/副本 SHA-256 验证后复制到新目标；同名冲突只提供比较/另存，不默认覆盖。修复只从已验证副本复制。
| 导入预设 | 版本化 JSON/SQLite 模板，字段白名单、规则校验、预览纯函数；预设同步不携带用户路径或凭据。
| 客户交付包 | 后台任务生成所选文件副本、联系表和 manifest/checksum；每项有来源 ID 和哈希；不改原件，生成前核对输出空间。
| 本地智能检索 | 第一阶段 SQLite FTS5 + 结构化条件；后续可选本地向量索引并在设备删除时级联清理。云端语义检索默认关闭，需单独授权和字段脱敏。
| 废片处理 | 质量分析器只产生候选/原因/模型版本；复制到 `待处理废片/` 后保持源文件只读；UI 与 Agent 调用同一 allowlisted cleanup 工具，仅允许对已确认的隔离副本移入系统废纸篓。
| 跨端记录/会话 | outbox 同步 job、target 摘要、任务报告、Agent 对话/动作摘要、约 512px 缩略图和可关闭的完整路径/电脑名；每条事件带 owner/device、sequence、schema_version；令牌走系统凭据库，原片和精确 GPS/EXIF 不入云，支持用户删除与注销级联删除。
| 微信扫码 | 官方网站应用扫码登录形态；系统浏览器 OAuth；FastAPI 校验 state/nonce、服务端换 code、签发短时一次性桌面回跳票据；AppSecret 仅存在服务端 Secret 管理。开放平台资质、域名校验、UnionID 绑定先做验证门。

### 12.1 图像质量模型和指标

- 本地模型默认免费且不向第三方上传原片。照片首选“可解释信号 + MUSIQ 排序候选”：OpenCV 计算高光剪切比例、清晰度/运动模糊信号；MUSIQ 仅作为无参考图像排序信号。视频采用抽帧和片段级曝光、清晰度/运动模糊信号，不直接把单帧图像质量模型当作视频真值。按相机、RAW/视频解码器和媒体类型校准阈值。
- 云端模型可选，用户自带 API Key（BYOK），界面显示模型和用量；密钥只进系统安全存储或受控 Secret，不进前端明文、日志或项目仓库。云端视觉复核只有用户逐张选择照片并逐次确认后才上传给其选择的模型服务商。首版视频质量分析在本地完成；视频/抽帧云端发送须后续单独授权。模型输出仅供解释/复核，不可直接触发清理。
- 验收目标不是已达到的准确率。照片与视频分别建立标注测试集并单独报告；照片集建议至少 1,000 张可用照片、每类明显缺陷至少 300 张，并包含高调、人像浅景深、长曝光等难负样本。两类媒体分别以候选 precision ≥98%、可用素材误报率 ≤1%、明显严重缺陷 recall ≥80%为目标；视频还需按片段/抽帧策略建立独立集。阈值、媒体类型、解码器和数据集版本写入报告。
- 拒识/低置信样本转人工复核；不满足误报目标时不自动扩大批处理范围。

## 13. 登录、个人网盘与免付费签名发布

### 13.1 登录接入建议

产品同时提供手机短信验证码、邮箱验证码和微信扫码。短信/邮箱验证码通过受管认证服务发送并限流、防滥用；微信桌面登录优先采用“系统浏览器 + 微信开放平台网站应用扫码”方案：桌面端请求短时登录会话，系统浏览器完成扫码，FastAPI 校验 state/nonce、服务端换取身份，再用一次性深链票据回到 Tauri。应用密钥和第三方 access token 只留在服务端，桌面仅收到影序短期会话令牌。CloudBase 是否直接提供所需的认证渠道和连接能力需要验证；在资质/API 权限未就绪前不接入真实登录。官方接入指南：[微信开放平台网站应用微信登录](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)。

### 13.2 百度网盘

- 只支持个人用户自己的百度网盘；通过独立 Provider adapter，只通过官方明确允许且应用已获批的 OAuth/API，不逆向客户端或网页接口。
- 本地副本完成 SHA-256 校验后才进入用户勾选的云盘队列。先用小文件完成授权、上传、远端校验，再验证大文件分片/断点续传、同名冲突、暂停/重试。各目的地独立记录结果；一家失败不回滚本地成功或另一家成功。
- 百度官方开放平台说明见[百度网盘开放平台](https://pan.baidu.com/union/document/entrance)。百度接口必须以用户账号和应用实际获批结果为准。
- App Secret/用户 token 放服务端 Secret 管理或系统凭据库；若官方流程要求内置客户端密钥，先核验官方允许的桌面授权模式，不能安全落地前不发布上传功能。

### 13.3 免付费平台签名的更新和分发

1. 不购买 Apple Developer ID 或 Windows 商业代码签名证书，不做 Apple 公证；按用户决定接受 macOS Gatekeeper 与 Windows SmartScreen 等系统提示，提供清晰、经当前系统版本核验的手动安装说明。未签名安装器的安装/更新提示须分别在 Windows/macOS 实测。
2. Tauri updater 的应用自有更新签名与平台代码签名/Apple 公证是不同机制。使用免费自有 updater 签名密钥校验更新包；私钥只存 GitHub Actions Secret 或受控离线保管，不提交到仓库。更新元数据和包可优先存 GitHub Releases；若用户关闭自动更新，仍提供手动下载安装及 SHA-256 校验。
3. 发布安装包放 GitHub Releases，原 GitHub Pages 仅更新版本、说明、下载和安装指引，不另建官网；页面与 Release 额度及平台政策在每次发布前复核。

该方案以低成本和用户接受手动安装提示为前提。updater 自有密钥只证明更新包完整性，不能消除系统关于开发者身份的警告，也不代表 Apple 公证或 Microsoft 信任签名。

## 14. v0.4 实施顺序与决策门

1. 桌面前端原型先完成：插卡自动扫描/预检、用户确认目标和命名、照片/视频质量复核、恢复/健康审计、深浅主题、预设、Agent 会话、交付包及设置页；演示数据明确标注，每小项交互走查。
2. 用户确认前端后，设计 Rust/SQLite 接口；先完成文件安全、任务恢复、审计和报告的本地闭环。
3. 分别以照片集和视频片段集验证质量模型；本地模型默认免费，云端 BYOK 可选且照片逐张授权。指标未达标时保留人工判断，不自动清理。
4. 单独验证短信/邮箱验证码、微信开放平台账号、百度网盘授权、CloudBase 账号绑定和数据删除；第三方审批/密钥/配额未验证前不把按钮宣称为可用。
5. 发布前演练 Tauri updater 自有密钥签名、Windows/macOS 未签名安装警告与手动指引、Release 资产校验和原下载站更新；不将未购买的证书/公证写为发布前提。

### 14.1 顺序推进与授权闸门

- 严格按阶段依赖顺序推进，每个小切片完成后先检查和修复，再进入下一个切片；不跳过未完成的前置阶段。
- 当下一步需要用户授权、开通 API、提供密钥/令牌或完成第三方审核时，暂停依赖该权限的工作，向用户说明具体 API、scope/权限、官方获取入口和安全配置方式；收到用户确认已经配置完成后再继续。
- 不要求用户把密钥、密码或令牌发在聊天中；使用官方控制台、GitHub Actions Secrets、系统 Keychain/Credential Manager 或其他受控秘密管理方式。未取得权限时，不用假凭据或 mock 声称真实 API 流程已通过。
- 与该凭据无关的阶段不用于绕过等待点；只有用户完成当前授权闸门后，才按既定顺序进入依赖它的下一步。
