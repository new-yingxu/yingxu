## 构建与隔离

构建前检查无其他 cargo/rustc/宿主构建进程。不修改 backend 源码、Cargo 配置或 tauri.conf.json。使用已有源码，独立 target，并通过临时环境参数设置独立应用标识，避免与旧应用数据库/单实例混用：

```sh
env SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk \
 CARGO_TARGET_DIR="$PWD/desktop-ui/evidence/r3-cargo-target" \
 TAURI_CONFIG='{"identifier":"app.yingxu.desktop.r3","productName":"影序桌面R3本地验收"}' \
 cargo build --manifest-path backend/tauri-host/Cargo.toml --locked
```

这是本地调试 bundle，依赖开发服务器 127.0.0.1:5173，**不是离线发行包**。真实 macOS 窗口加载当前 Vue 页，显示“已连接 Rust / SQLite”“真实登录未连接”，通过独立本地联调入口进入；没有伪造登录会话。数据库位于 `~/Library/Application Support/app.yingxu.desktop.r3/yingxu.sqlite`，不与 next/正式应用共用。
