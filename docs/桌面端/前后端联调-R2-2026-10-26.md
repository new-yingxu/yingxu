## 已实现的桌面准备

- AgentMatch 改为 kind=media（media 字段）或 kind=job（deviceId/jobId/sequence/state/source）。App 分别展示媒体元数据和已同步任务摘要，不将云任务伪装为 MediaFile。
- 浏览器 mock 明确映射为 media 分支，原有媒体演示回归正常。
- 新增 src/api/cloud.ts，仅为客户端准备，**没有接入 createDesktopApi 工厂**，不会自动启用线上服务。
- 依据云端独立工作树 v8 草案，准备 GET/PUT 同步偏好、POST Agent turns、GET session turns、确认式 DELETE session、GET session-deletions。
- 会话与轮次编号由调用方保留，响应关联/持久化未确认则报错，禁止静默生成新编号重试。410 SESSION_DELETED 保留。
- 删除请求必须显式 confirmed=true。删除记录游标与任务游标/设备 sequence 分离；当前只返回类型化数据，不宣称已实现账号缓存和 outbox 清理。
- HTTPS、拒绝跨站重定向、omit cookies、短时用户 token 注入、不存 token、不回显网络错误中可能出现的敏感参数。**CloudBase 服务端 APIKey 不能用于此客户端。**
- 正式身份桥、用户 token 签发、账号隔离存储、会话删除本地缓存清理、云动作授权桥、outbox 传输及真实部署均未完成。
