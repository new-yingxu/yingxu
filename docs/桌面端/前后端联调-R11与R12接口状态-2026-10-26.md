- 变更前快照位于 `desktop-ui/evidence/r12-backend-snapshot-20261026/`；快照时 `agent.rs` 不存在，`api.rs` 与 `lib.rs` SHA-256 记录在 `SHA256SUMS`。本次仅接管 `backend/core/src/agent.rs`、`api.rs`、`lib.rs`，此垂直切片结束后将这些 Rust 文件恢复只读。
- 新增 `agent.tools`、`agent.executeTool`、`agent.searchMedia`、`agent.getMetadata` 与 `agent.getBackupJob` RPC：当前设备 SQLite 索引/任务只读；工具参数采用严格白名单并拒绝额外字段（包括 `path`、`command`）；模型侧搜索/任务/元数据结果只含 mediaId、名称、类型、大小、质量状态及宽高/时长白名单，不含路径、EXIF/GPS、指纹或哈希；任务返回裁剪过的状态/计数，不含来源、目标和单文件路径。
- 新增 Tauri `agent_open_item(mediaId)` 宿主命令：仅主窗口可调用；按索引 mediaId重新校验来源目录授权、文件指纹、规范路径与符号链接，再调用固定系统默认打开器（macOS `/usr/bin/open`、Windows `ShellExecuteW`），写本地审计和 receiptId。命令不接受路径、URL 或命令字符串。通用 core RPC 的 `agent.openItem` 仍返回 `NATIVE_OPENER_REQUIRED`，强制经宿主安全入口；不存在的索引素材返回 `MEDIA_NOT_FOUND`。
- 验证通过：`cargo fmt --manifest-path backend/Cargo.toml --all -- --check`；`SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk cargo test --manifest-path backend/Cargo.toml -p yingxu-core --locked --offline`（30 单测、33 集成测试）；Agent 定向测试 3/3；`cargo check --manifest-path backend/tauri-host/Cargo.toml --locked --offline`。SDKROOT 仅对单条命令覆盖，未改系统 SDK 选择。
