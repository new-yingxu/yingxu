## 1. 产品定位与边界

影序面向摄影师和影像资料管理场景，管理素材导入、备份、校验、整理、质量筛选、检索、转移、云盘上传、Agent 操作和跨设备查看。原片安全、任务可追溯和失败可恢复优先于自动化程度。

本会话只开发 Windows/macOS 桌面端。移动端采用 Expo，由用户朋友负责；提供的 Android 1.0.0 包只作为桌面视觉一致性的参考，不在本会话修改、构建或验收移动端。两端需保持品牌颜色、状态含义和核心任务字段一致。

官网不另起项目，沿用现有下载站 <https://yingxu-app.github.io/smart-media-backup/download/>；本次读取返回 HTTP 200。当前页面仍展示旧版 Windows v1.0.34、macOS v1.0.40 本机候选和 Android 内部预览；新版上市时再更新原站的下载信息和版本说明。官网改版、独立托管和宣传页面不属于本次桌面端开发范围。

Agent 理解用户意图并调用受限工具；复制、哈希、改名、移动、上传由确定性任务执行。模型不能直接执行任意命令，也不能跳过授权或确认。

## 2. 旧版 1.0.40 必须覆盖的功能

已从安装包页面资源核对到以下功能和页面。尝试读取运行界面时，应用启动超时，因此本清单是静态页面证据，不代表本轮完成了运行验收。

### 2.1 复制新内容

- 插入存储卡/移动盘后自动扫描和预检，但不自动开始写入；用户确认备份目标和命名预览后才开始任务。目标支持本地磁盘/移动硬盘以及用户授权的百度网盘、夸克网盘；不支持 NAS/局域网共享目录。
- 选择一个或多个备份目的地，预检并显示可用空间；先将文件复制到本地目标并通过 SHA-256 校验，再上传到用户勾选的网盘。
- 目录命名可配置时间、事件、地点、设备、照片/视频、自定义文本和不使用字段的顺序，并预览层级名称。智能命名先预览新旧名称，用户确认后执行；确认的规则可保存为预设并供后续任务套用，开跑前仍展示目标与命名摘要。
- 可将 Pocket 收到的拍摄信息用于命名。
- 照片和视频均纳入备份与质量分析；RAW、sidecar/元数据和其他关联文件在备份中保留。无法解码或不支持分析的文件仍可备份，并明确标记未分析。
- 支持 SHA-256 校验或用户明确选择跳过校验；显示阶段、总进度、当前文件、速度、复制/跳过/校验/失败数量；支持暂停、继续、取消。
- 目标出现同名文件时按 SHA-256 处理：内容相同则跳过；内容不同则保留既有文件并给新文件增加序号，不覆盖。
- 多目的地逐个显示结果；百度/夸克任一上传失败时保留本地备份成功状态，将云端结果标成部分完成，并允许单独重试失败目的地。生成可追溯报告并记录每项目标结果。

### 2.2 转移老内容

- 选择来源和目标，扫描前说明只读来源；可筛选照片、视频、其他并逐项选择。
- 可分析疑似废片、相似照片和完全重复文件；显示候选和理由，重复项由用户确认。
- 可手工填写事件/项目名或请求 AI 命名建议。
- 转移前说明来源删除条件。只有目标副本通过 SHA-256 校验，或目标已有副本再次确认哈希相同，且用户明确确认，才可移除来源。
- 失败、取消、校验不通过、来源变化、磁盘断开或目标冲突时保留来源；可取消剩余任务。
- 废片候选可放入待确认目录，不得静默销毁原片。

### 2.3 归档记录

- 支持按状态、目标类别/位置、项目/名称、拍摄时间、设备、地点、照片/视频和时间范围筛选搜索。
- 区分成功、部分完成、进行中、取消和失败；打开任务详情、查看报告和定位目标文件。
- 支持修改记录名称；清空历史需二次确认，并明确不删除已备份媒体文件。

### 2.4 偏好设置与旧版集成能力

- 通用设置：端口、启动行为、校验方式、恢复默认值、已备份文件统计。
- 百度网盘和夸克网盘：分别授权和配置个人账号、查看连接状态、选择目标、跟踪上传并处理失败；只接官方允许的 API，不绕过权限；密钥不得明文进前端、日志或公开仓库。
- AI 自动命名可关闭；旧版页面提供 Ollama 与 OpenAI 兼容 API。新版本用供应商适配层，AI 不应成为离线备份前置条件。
- 高级设置：Webhook 通知、最大速度、相似度阈值、默认目录层级顺序。
- 跨设备同步：按账号同步备份记录、Agent 对话、最长边约 512px 的压缩缩略图、电脑名称和完整本地路径；路径与缩略图各有关闭开关，不同步原片。手机只查看桌面路径，不可通过路径打开或控制桌面文件/备份。
- Pocket：保留配对、查看任务进度/速度/历史和回传拍摄备注等兼容能力；新版统一走账号/设备同步协议，不沿用无 TLS 的局域网传输实现。手机 Agent 可查云端同步数据并管理手机自己的本地备份，不控制桌面备份。
- 同步数据保留到用户手动删除；注销账号时一并删除账号云端同步数据。
- 存储概览、主题切换、关闭窗口后后台运行、托盘/菜单栏恢复窗口。

## 3. 新版本功能范围

### 3.1 智能影像管理

- 读取常见照片/视频元数据、拍摄时间、设备型号、可读 GPS；支持 RAW 格式识别与元信息读取。
- 按时间、事件、地点、设备、类型和自定义规则分类/命名，执行前预览，冲突不得静默覆盖。
- 筛选疑似过曝、失焦/模糊、重影、损坏和无法解码素材，显示预览、原因和置信度。
- “去掉过曝”首版解释为识别和调整建议；若生成修复图，必须保存为独立派生文件、保留原图和关联记录。不能承诺还原已经剪切丢失的细节。
- SHA-256 用于字节完整性和精确重复；视觉相似/连拍另做感知分析，不自动等同重复、不默认删除。
- 本地资料库支持文件名、日期、设备、项目、类型、质量标签和可索引元数据搜索。FTS5 是全文检索组件，不自动理解图像语义。

### 3.2 Agent 助手

- 自然语言查找文件，展示匹配原因、路径和元数据；用户要求时打开文件或目录。
- 查询任务和历史，回答备份位置、速度、校验、失败、跳过和报告内容。
- 预览后改名、移动、整理文件；每次操作记录对象、旧值、新值、结果和发起设备。
- 用户授权后发起百度网盘或夸克网盘上传，明确显示上传对象和远端目录。
- 手机 Agent 可查询账号云端同步数据、操作手机本地备份；桌面 Agent 可操作当前桌面允许访问的本地资料。手机端不控制桌面备份任务。
- 查找/预览可直接完成；改名、移动、上传、清理和其他有副作用的操作，先展示具体对象与目标并由用户确认；Agent 不可扩权、执行任意 Shell 或隐藏副作用。

### 3.3 四端账号与任务共享

- 产品层面保留 Windows、macOS 与 Android/iOS 的账号、设备和任务状态协同；移动端由 Expo 项目及其负责人实现，本会话不开发移动端页面或功能。
- 桌面端提供可供移动端查看的任务状态字段：速率、进度、阶段、逐目的地结果、最近错误、桌面在线状态和最后同步时间。
- 断线后先恢复快照再补增量；桌面离线时不得伪报远程命令已执行。
- 同步备份记录、Agent 对话、最长边约 512px 的压缩缩略图，以及可关闭的完整本地路径/电脑名称；手机对路径只读。原片不上传到影序云端。用户可分别关闭缩略图与路径同步。
- 手机 Agent 使用云端同步资料和手机自己的本地备份工具，不调用桌面设备的本地工具；桌面 Agent 仅使用当前桌面端获批工具。
- 同步数据保留到用户手动删除；账号注销时一并删除。传输、访问控制和存储加密按 CloudBase 可验证能力落地。

### 3.4 桌面端视觉基线

颜色依据提供的 Expo 移动端源码样式定义；桌面端沿用相同语义色，按大屏信息密度调整留白和布局，不另设一套品牌色。首轮同时支持浅色/深色主题切换；深色主题沿用品牌色语义并为背景、文字、边框分别设置可读的暗色令牌。

|---|---|---|
| 品牌主色 | `#273D31` | 主按钮、选中导航、重点操作 |
| 品牌深色 | `#253A2F` | 任务状态/强调面板 |
| 页面底色 | `#F4F2ED` | 应用主背景 |
| 卡片底色 | `#FFFFFF` | 内容卡片与浮层 |
| 主要文字 | `#1E2420` | 页面标题和高优先级内容 |
| 正文文字 | `#6F706A` | 说明、次级信息 |
| 分隔/边框 | `#E9E6E0` | 卡片、控件和列表分隔 |
| 成功绿 | `#27804A` | 成功、连接正常状态 |
| 进度金 | `#DDBA76` | 任务进度、少量强调 |

## 5. 安全与状态规则

1. 默认只读来源；新增文件写到用户选定目标。
2. 不静默覆盖已有文件；先预检路径、权限、空间、符号链接和来源/目标嵌套。
3. 普通备份只复制；转移任务只有在目标副本通过 SHA-256 校验、来源未变化且用户二次确认后才移除来源。改名、移动、云上传、清理、清空历史和分享报告前，显示对象/目标/影响并确认。
4. SHA-256、视觉相似和质量筛选分别表示不同事实；质量判断不直接触发删除或原片改写。
5. 每个目的地独立记录状态；同步失败不改变本地备份结果。
6. 报告包含任务 ID、版本、来源、目的地、时间、数量/容量、速率摘要、校验、跳过和失败原因；GPS/路径等敏感字段按最小必要处理。

任务终态统一为成功、部分完成、已取消、失败和暂停，并展示已处理项、可重试项、来源安全状态与恢复步骤。

## 8. v0.4 推荐扩展功能

以下是对既有范围的增量建议，按“先安全闭环、再提高效率”排序；不代表已实现。

### P1：备份恢复与健康审计

- 从健康备份副本选取文件恢复到用户指定位置；恢复前校验源副本 SHA-256，遇到同名文件提供比较/另存选项，默认不覆盖。
- 定期或手动抽查备份副本哈希，报告缺失、损坏、离线目标和最近校验时间。可从另一份已验证副本修复单个目标，并保留修复前后审计记录。
- 提供相机/项目导入预设：命名规则、目标组合、目录结构和质量筛选策略可保存复用；每次执行前显示预览。

### P2：交付与搜索效率

- 生成客户交付包：所选照片/视频副本、可选联系表/预览图、清单与 SHA-256 校验文件。生成物写入独立交付目录，原始素材保持不变。
- 增强本地自然语言检索：先基于文件名、时间、设备、地点（本机）、备注和任务报告；后续评估本地向量索引，云端语义检索需单独授权且不得默认上传原片。

### 废片处理与质量筛选口径

- 产品统一称“废片处理”。备份/筛选阶段只标记候选并将候选副本放入目的地的“待处理废片”目录，不删除来源卡或原目录文件。
- 用户在候选列表逐项确认后，可由按钮或明确的 Agent 指令清理。清理仅作用于该待处理目录内已确认的副本，先移入系统废纸篓/回收站，保留可恢复窗口；永久删除单独确认。Agent 不得凭模型结果自动清理。
- 识别严重过曝、明显失焦、非预期运动模糊/重影、损坏或不可解码照片和视频；保留高调、长曝光、景深虚化等有意创作的反例。视频质量分析采用抽帧及片段级信号，结果展示原因、模型版本和不确定性。
- 质量验收门槛是目标而非已达到的准确率：照片和视频分别建立测试集并单独报告结果；照片集先覆盖至少 1,000 张可用照片及每类明显缺陷至少 300 张。每种媒体分别以候选精确率不低于 98%、可用素材误报率不高于 1%、明显严重缺陷召回率不低于 80%为目标。视频需要按片段/抽帧规则建立样本集；达不到目标或置信度不足时转人工复核，不自动删除。

### 手机同步范围

- 必须同步备份记录与 Agent 会话（用户/助手文本、最终回复、工具动作摘要和结果），以及自动生成的最长边约 512px 压缩缩略图；缩略图可在设置关闭。完整本地路径与电脑名称可同步到手机供查看，提供关闭开关；手机不能通过该路径打开或控制电脑。
- 原片、访问令牌和精确 GPS/EXIF 不上传影序云端。同步数据保留至用户手动删除，注销账号时一并删除。账号权限需隔离，路径和对话作为个人敏感数据处理。
- 手机 Agent 查询云端资料并管理手机自己的备份，不控制桌面备份任务。

### 登录与发布建议

- 登录同时提供手机短信验证码、邮箱验证码和微信扫码。桌面微信扫码优先评估开放平台“网站应用扫码登录”：系统浏览器展示二维码，服务端处理回调和 code 换取身份，再通过一次性票据回到桌面端；应用密钥只留在服务端。开放平台资质、短信通道、回调域名及账号绑定条件需验证。Expo 移动端由朋友实现，不纳入本会话开发。
- 沿用现有下载页；发布文件放 GitHub Releases 并提供 SHA-256，网页只更新版本和链接，不把大安装包提交到 Pages。系统安装提示、updater 自有签名和低成本分发方案见技术框架。

## 9. v0.4 优先级与审阅边界

前端仍先行：先在 Windows/macOS 确认页面与演示流程，再冻结接口并做后端。v0.4 首轮包含深浅主题、插卡扫描预检和确认式备份流程、照片/视频质量复核、恢复/审计、导入预设、Agent 会话、跨端同步及交付包入口；视频模型精度、向量搜索和云端语义搜索需后续验证或评估。

旧版静态页面核对、Android ZIP 配色核对和网站 HTTP 读取不构成运行验收；本草稿也不代表任何新增能力已实现。

## 10. 开发推进准则

- 按已确认的阶段和依赖顺序逐项推进；每项完成后先闭环检查，修复问题再进入下一项。
- 若下一步必须由用户授权、开通第三方 API、提供密钥或完成账号/资质审核，则停在该依赖点，列清需要的权限或材料，并等待用户完成后再继续相关步骤；不绕过授权，也不以模拟数据冒充真实接入。
- API 密钥、密码和令牌不要求用户粘贴到聊天中；优先通过官方控制台、系统凭据库或受控 Secret 配置入口提供。依赖的授权尚未完成时，不推进依赖该凭据的实现/验收。
