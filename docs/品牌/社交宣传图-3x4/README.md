## 宣传边界

- 不宣称自动删除或修复影像；质量提示仅供人工复核。
- 原片不会默认上传；任务元数据等同步行为以用户设置为准。
- 手机端不作为桌面文件操作遥控器。
- 图中未嵌入网址、价格、下载量或版本状态，发布时可按实际发布信息另配正文。

## 生成方式

使用 Codex 内置图像生成工具制作 9 张无文字插画，再基于插画分别生成中文排版成稿。项目内 SQL 文件均是 CloudBase/PostgreSQL/MySQL 数据库 schema，与图像模型或画质参数无关，因此未下载或改动 SQL。
