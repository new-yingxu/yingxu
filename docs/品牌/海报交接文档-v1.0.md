## 一、一句话认识产品

**影序 YINGXU** 是一款面向摄影师和影像工作者的**本地影像备份与整理软件**。

它做的事：把相机卡、移动硬盘里的照片和视频，扫描 → 复制到多个本地目的地 → 逐文件 SHA-256 校验 → 按拍摄信息整理命名 → 建立可检索的资料库 → 用对话式 Agent 处理重复操作。

**核心立场（贯穿全部物料）**：原片只读，副本可校验，数据留在你自己的硬盘上，不经过任何云端。

## 二、必须使用的文案

### 主标题（原文使用，二选一）

- 首选：**把影像的备份与秩序，留在你自己的硬盘上。**
- 备选：**原片只读，副本可校验。**

### 副标题（原文使用）

> 影序负责扫描、复制、校验、整理和检索。原片始终只读，副本逐文件比对 SHA-256；断网、离线、换盘都能用，不需要把照片交给任何云端。

### 品牌署名（原文使用）

- 中文名：**影序**
- 英文名：**YINGXU**
- 品牌短句：**本地影像备份与整理**

### 四条功能短句（原文使用，可作为四个并列信息块）

| 词 | 说明文案 |
|---|---|
| **备份** | 按来源目录生成计划，逐文件复制到 1–8 个本地目的地。先预览再执行，任务可暂停、可恢复，绝不覆盖已有文件。 |
| **校验** | 复制过程与完成后都做 SHA-256 比对，副本清单可随时复查。校验失败的条目单独列出，不会写成「成功」。 |
| **整理** | 用 EXIF 拍摄时间、机型与事件规则命名，支持 RAW 内嵌预览与视频元数据。质量信号只输出「待复核」，不自动删片。 |
| **Agent** | 把重复操作交给对话式助理：生成计划、解释失败原因、汇总报告。所有危险动作都要你确认后才执行。 |

### 差异化短句（原文使用，适合做对比区或角标）

> **和网盘不是同一件事。**
> 原片不先上传；副本逐文件校验；断网也能用；删除要二次确认且可撤销；大文件走本地直读，不受上行带宽限制。

## 三、三端内容要点

海报如需体现"多端"，按下面写，**不要给手机端编造它没有的能力**。

### 桌面端（主角，Windows / macOS）

界面共 12 个功能页：工作台、复制新内容、转移、影像资料库、归档记录、任务详情、Agent、账号与设备、命名预设、健康审计、交付包、设置。

可提炼的能力点：

- 一次备份到 1–8 个本地目的地，每个目的地独立显示成败
- 逐文件 SHA-256 校验，失败项单列，绝不显示为全成功
- 任务可暂停 / 恢复 / 取消 / 失败目标单独重试
- 影像资料库：按文件名、日期、机型、质量状态检索
- 照片质量信号（过曝、模糊、重影）只标「待复核」，不自动删片
- 交付包：生成含 SHA256SUMS 清单与 HTML 联系表的完整包
- 健康审计：对所有已登记副本回读校验，定位损坏副本并用健康副本恢复
- 关闭窗口后继续在系统托盘/菜单栏后台运行

### 移动端（Android / iOS）

定位是**只读伴侣**，不是把桌面搬到手机。

- 查看桌面任务的实时进度、速度、阶段、结果和最后同步时间
- **只读**：手机不能控制桌面任务、不能操作电脑上的文件
- 手机素材备份：扫描手机里的照片视频，确认后备份到本机可访问目标或已授权的网盘
- Agent 按设备隔离，只能查询本账号已同步的数据
- 原片与完整路径不同步

### 网页端（官网）

承载四件事：产品介绍、功能说明、下载入口、版本说明与隐私政策。

- 下载页按平台分流（macOS / Windows / Android / iOS）
- 版本号与发布资产保持一致，不硬编码
- 明确展示「已能用」与「还没做」的边界

## 四、视觉规范

### 色板（直接取用，勿自行发明主色）

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面底色 | `#f4f2ed` 米白（纸感） | `#191f1b` |
| 卡片 | `#ffffff` / `#fdfcf9` | `#222a24` / `#252d27` |
| 主色（品牌） | `#273d31` 深松绿 | `#47644c` |
| 主色次阶 | `#344d3e` | `#537256` |
| 强调绿（校验通过） | `#27804a` | `#83bd8c` |
| 金色（点缀/高光） | `#ddba76` | `#d9ba75` |
| 警示红（失败项） | `#a33a32` | `#e28d82` |
| 正文 | `#1e2420` 墨绿黑 | `#edf1eb` |
| 次要文字 | `#6f706a` | `#b5bbb3` |
| 分割线 | `#e9e6e0` | `#38413a` |

**用色倾向**：以米白 + 深松绿为主调，金色只做少量点缀（徽章、数字高光、分隔线），红色只在"失败/警示"语境出现，不可做大面积装饰。

### 字体

`PingFang SC` / `Noto Sans SC`，回退到系统无衬线。标题可用较重的字重，正文保持轻量；不建议用衬线体或手写体，会偏离工具气质。

### 品牌标志的视觉语言（重要，可据此做图形元素）

现有 logo 是一个**深绿圆角方块（30×30，圆角 9px）内嵌 2×2 四个米白色圆角小方块，整体逆时针旋转约 4°**。四个点代表"多目的地/多副本"，也可理解为影像网格。

海报上可以：
- 直接放大该方块作为图形锚点
- 把 2×2 点阵延展为背景纹理或分隔符
- 保持那 4° 的轻微倾斜，作为品牌独有的"不呆板"感

### 界面质感（截图或重绘时参考）

- 圆角：卡片 10–14px，按钮 8–10px，标签用全圆角（99px）
- 阴影极轻：`0 8px 24px rgba(40,43,35,.045)`，几乎看不见，靠留白和分割线分层
- 留白充足，信息密度低，接近纸质工作室台账的观感
- 图标为线性描边风格，不填充

## 五、画面构成建议

### 方案 A：桌面端为主（推荐）

左或中部放桌面端界面（工作台/任务详情），右侧或下方压主标题；用 2×2 点阵做背景纹理；金色细线勾出"副本 A / 副本 B / 校验通过"的信息块，体现多目的地与校验。

### 方案 B：三端协同

三个层级的设备框（桌面大、平板/手机小、浏览器窗口最轻）排成错落层次；每一端配一句该端独有的能力短句；底部一行"原片只读 · 副本可校验 · 断网可用"。

### 方案 C：概念化（不出现界面）

用"相机卡 → 多块硬盘 → 校验印章"的抽象图形链路表达流程；深松绿底 + 米白线条 + 金色校验标记；主标题用大字号排版占主视觉。

### 三种方案都建议出现的元素

1. 主标题（字号最大，占据视觉重心）
2. 品牌名「影序 YINGXU」+ 品牌短句
3. 「原片只读 · 副本可校验」这一句（可作为副标或角标）
4. 四条功能词（备份 / 校验 / 整理 / Agent）至少出现三个

## 六、红线（必须遵守）

1. **不得写"云端备份""同步到云""照片上传到服务器"**——影序的立场是原片留在本地。
2. **不得把"识别过曝/模糊"写成"自动修复""自动删除废片"**——产品只输出「待复核」标记，不自动动原片。
3. **不得宣称"支持所有 RAW 格式"**——只在已验证的机型样本范围内支持，海报如需提及，用「支持主流相机 RAW 预览」。
4. **不得出现"已完成正式签名""已上架应用商店"**——当前是测试版、无正式签名证书。
5. **不得使用他人照片作为素材**——如需照片，用抽象图形、色块或纯排版代替；确需实拍素材请先确认授权。
6. **手机端不得画成可以控制电脑**——它是只读查看。
7. 不要出现具体价格、免费承诺、下载量、用户数等未经验证的数字。
