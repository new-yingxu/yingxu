# Pocket 与桌面端功能边界（2026-10-29）

## 当前移动端切片

| 功能 | Pocket 现状 | 本次实现/边界 |
|---|---|---|
| 手机照片和视频备份 | 本机扫描、预览、复制、SHA-256 校验、暂停/取消与恢复 | 保持手机本机写入能力；不把手机后台任务描述为持续运行 |
| 旧归档导入 | 可从手机/外接存储选目录导入 | 保持移动端本机流程 |
| 本机历史与报告 | 可查看、导出、删除本机记录 | Agent 增加只读查询，不返回本机绝对路径 |
| AI 审片 | 用户选择照片后调用视觉模型 | 只在用户明确要求时调用；UI 说明素材会发给配置的视觉服务 |
| Agent | DeepSeek 对话和手机白名单工具 | 增加手机任务状态/历史和已配对电脑状态/历史只读查询；显示实际工具结果 |
| 桌面任务 | 已配对电脑状态和历史 | 手机只读；旧 TCP 服务端也拒绝启动、暂停、取消命令 |
| 账号/跨端同步 | 旧 Pocket Firebase 登录与元数据同步 | 尚未接入新桌面端 CloudBase/FastAPI 契约，不能视为跨端账号同步已闭环 |
| 桌面资料库、恢复审计、导入预设、百度/夸克授权 | 桌面端能力 | 当前手机端未实现；需逐项冻结 API 与授权边界后再开发 |

## 验收边界

- 桌面端任务控制不得通过手机触发；仅在桌面端执行。旧 TCP 服务端不再接受 `desktop.start`、`desktop.pause`、`desktop.cancel`。
- Agent 的状态/历史工具只投影必要字段，不读取或返回桌面绝对路径、媒体原片或凭据。
- 手机 Agent 的 DeepSeek 对话和 AI 审片属于外部模型请求；界面必须如实提示。
- 当前桌面仓库与 Pocket 使用不同远端仓库和后端契约。新桌面端完整账号同步、资料库/恢复等能力不因 UI 存在而认定已接通。
- 用户视角 UI 复测和 Android Emulator 安装验收应分别记录；静态类型检查或单元测试不代表 APK 安装/运行通过。
